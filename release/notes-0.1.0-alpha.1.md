# 面包光谱 / SoftLoaf Spectral 0.1.0-alpha.1

首个**源码测试版（prerelease）**，供开发、审阅及公开数值测试。没有安装包；
桌面应用所需的胶片／相纸曲线和冻结模型未附带，下载后不能直接运行完整应用。

源码包含：

- C++23 float64 参考内核、Metal / D3D12 后端与 CPU 处理退路。
- 光谱配方、试片、负片正相工作台及中英文界面。
- VISION3 5203/5207/5213/5219、E100、Velvia 50/100、Provia 100F 和五款 Kodak RA-4 相纸的材料接入代码；负片材料与 APD／光学放大分支分开。
- 集成的 RawTherapee 5.12 源码及修改记录；两阶段 RAW 保留缓存、分块图像导出和测试。
- 面包光谱 LOGO、直接取得并核对的五份 CIE 原始表及其 CC BY-SA 4.0 来源记录。

未附：制造商 PDF、未审光谱曲线、采样库／冻结模型、照片、私人色卡测量、
扫描标定、工作区、缓存或凭据。其他项目的胶片／相纸／滤片曲线未作为数据附送。
原始代码为 AGPL-3.0-only；第三方组件保留各自许可。

构建与资料清单：[`docs/source-release.md`](../docs/source-release.md)。
公开测试通过只证明列明的数值与契约检查；真实胶片色彩精度、完整数据分发、
独立安装包、签名和公证仍有后续工作。

下载 `*-source.tar.gz`，用 `SHA256SUMS` 核验。`*-manifest.json` 列出不可变
源码提交和逐文件 SHA-256；GitHub 自动生成的 Source code ZIP/TAR 为同一标签源码。
