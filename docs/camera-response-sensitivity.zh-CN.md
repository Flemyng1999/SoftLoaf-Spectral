# 5207 翻拍的相机响应敏感度

2026-10-29，Issue #12。本次比较使用同一组 37 帧、同一个 000003 透射卡标定、
平场和片边读数。没有更改桌面应用的默认配方、源 RAW、已有拟合或成片。
全部数据、LUT、PNG 和研究页面保存在配置的外置数据卷。

| A7R V / ILCE-7RM5 | Solomatov、Akkaynak 2023，DNG 矩阵／自编码器**预测** | 400–700 nm，10 nm |
| A7R IV / ILCE-7RM4 | RawToACES／Weta Digital，设备字段 lightsaber | 380–780 nm，5 nm |
| A7R III / ILCE-7RM3 | 同上，各自机型文件 | 380–780 nm，5 nm |
| A7R II / ILCE-7RM2 | 同上，各自机型文件 | 380–780 nm，5 nm |

见[公共来源身份与哈希](../data/camera-response-sensitivity-sources.json)。A7R IV、III、II
是其他相机的来源测量，不能称作用户这台 A7R V 的独立实测。来源只声明相对
响应；未提供本次所需的光学链包含范围、绝对 QE、测量不确定度或仪器 FWHM。
数值网格间隔不等于仪器分辨率。实验按 DNG／RawToACES 的有效能量响应约定
计算，不把这些值认作每光子 QE 后再任意乘一次波长。

主比较统一用 400–700 nm，在线性非负原数值间插值到 1 nm 计算网格，
没有给 A7R V 预测数据补造两端。当前自由联合响应另保留 391–730 nm 版本、
裁至 400–700 nm 版本，A7R IV 也另计算 391–730 nm 版本。APD 输出仍保持
冻结的 360–730 nm 有限波段定义，不因扫描比较波段改变标准输出。

## 比较条件

全部采用同一 Status M 拟合的 5207 材料和三系数允许域，反求绝对透射谱后
才在输出分支积分 APD，连续 ADX16 进入锁定 ACES 2.0 SDR 100 nits／sRGB。
材质本身、原场景曝光与显示外观没有按相机曲线重新调色。

扫描前向函数是 `u_c = Σ_i T_i(a) E_i S_ic Δλ_i × k_c`。E 是扫描光与未知
光路透过率的合成能量谱，S 是给定相机响应。先消除来源通道幅度的任意比例，
再用同一卷的一次片边读数对齐。每个响应假设的片边增益只求一次，全卷固定；
它不是逐张白平衡或新测得的 Dmin。

两组实验分别回答不同问题：

- **各曲线重标定**：固定 S，用同一张卡的 24 个实测透射谱及相机读数，拟合
  三通道共用、非负的 E。使用间隔 10 nm、σ=10 nm 的高斯基和 ridge=0.1，
  不是为使某个机型胜出而逐个挑参数。相机通道尺度仅在训练色块上估计。
  按实物色卡的六列留出，每次排除同列全部四色块；没有把训练残差当留出误差。
- **固定同一有效光谱**：将 A7R V 预测所推算的 E 冻结，只替换 IV／III／II 的
  响应形状并做同一片边对齐。此组的共享光谱来自整张卡拟合，其色卡残差不是
  独立验证；主要用于观察相机形状变化。

联合响应、相机 S 和光源／光路 E 有不可辨识性。两组不是相加即可分解的
独立误差预算，也没有从卡上分别实测出灯与相机。原平场绿色剪切后的外推、
未知杂散光和片基材料误差仍存在。

## 色卡检查

| 条件 | 六列留出 RMS / D |
| --- | ---: |
| 当前自由联合响应，391–730 nm | 0.02960 |
| A7R V 预测，400–700 nm | 0.04708 |
| A7R IV，400–700 nm | 0.02415 |
| A7R III，400–700 nm | 0.02379 |
| A7R II，400–700 nm | 0.02559 |
| A7R IV，391–730 nm | 0.02386 |

当前自由联合响应采用嵌套调参，固定 S 各组采用预声明参数。它们的约束与
参数化不同，表格只描述对同一张卡的外层预测，不能作为物理相机型号排名。
同卡不同列仍不是另一张独立实测 5207 负片。

另用 σ=5／10／20 nm、ridge=0.01 检查主要先验：V 的留出 RMS 在
0.0454–0.0477 D，IV 在 0.0231–0.0295 D。这一范围内，V 预测较难解释
当前透射卡的趋势没有倒转。没有据此更改已冻结的主要成片参数。

## 成片差异

对固定画面区域做全卷均匀抽样，共 15,725 点。每个点都直接 float64 反演并
进入显示；以下统计不经过 3D LUT。使用 CIE 1931 2°、sRGB 解码后的 XYZ／
D65 相对 Lab 算 ΔE00。它是两个已显示结果的差异，不是实物颜色准确度。
全卷采用相同 +2 EV 观看使暗部便于检查；另保存完全相同条件的 0 EV 数值。

| 重标定结果相对当前联合拟合 | ΔE00 中位数 | P95 | 最大值 |
| --- | ---: | ---: | ---: |
| A7R V 预测 | 4.48 | 8.01 | 10.13 |
| A7R IV | 2.09 | 4.64 | 5.00 |
| A7R III | 2.31 | 4.94 | 5.34 |
| A7R II | 1.83 | 4.62 | 4.96 |

这些值包含不符合材料残差或数值条件的样本，没有默默丢弃；另保存双方有效
交集的分位数和计数。未曝光／漏光／材料域外部分的边界输出不能称为恢复成功。

| 直接成对比较 | ΔE00 P95 |
| --- | ---: |
| IV 与 V 预测，同一个估计光谱 | 2.42 |
| III 与 V 预测，同一个估计光谱 | 2.14 |
| II 与 V 预测，同一个估计光谱 | 2.09 |
| IV 与 V 预测，各自重拟合光谱 | 3.87 |
| III 与 IV，各自重拟合光谱 | 0.32 |
| II 与 IV，各自重拟合光谱 | 0.77 |
| 当前联合拟合裁掉两端，相对原范围 | 0.55 |
| IV 391–730 相对 IV 400–700，分别重标定 | 0.41 |

因此，此实验对相机响应及其光谱分解明显敏感；共同范围内的形状差异比本次
两个波段对照更显著。IV／III／II 重标定后的结果彼此较近，但与当前自由联合
拟合仍有可见差异。固定光谱和重新拟合光谱都影响结论，不能把所有变化归因于
相机一个元件，也不能因较符合当前色卡而认定 IV 的曲线就是 V 的真值。

## 图像和文件

主实验及波段对照每帧输出 3074×2048；固定同光谱组另输出 1、8、17、24 帧。
共十组响应／波段条件，生成十份 65³ CUBE／CLF 和 271 张完整 PNG。
同一个公共对数密度域用于所有 65³ 表，防止输入网格范围变化混入相机比较。
每表所有节点重新计算，独立 CUBE 读回、CLF 执行；图像通过 Metal 应用后，
使用既有分块 PNG 模块逐行核对像素、ICC 和分析身份。

逐帧记录直接参考与 65³ 查表的差异，因此 III／IV 等细微变化应优先看直接
计算数据，不能只凭 8-bit PNG 判断。另有第 17 帧的低分辨率逐像素 float64
参考图，不经过 LUT，专门核对视觉变化的方向。浏览页面及联系表采用同一个
固定画面裁切和 180° 旋转，仅供检查；完整图像保留翻拍范围和方向。

271 张完整 PNG 均逐行读回，像素、ICC 和分析身份一致。全卷抽样的 Metal
与独立 C++ float64 查表最大绝对差为 2.99e-7；65³ 与直接计算的单通道最大差
为 1.79 个 8-bit 码值，局部显示 ΔE00 最大约 1.04。因此表内小于 1 的直接
差异仍需结合查表和编码误差看待，不能用 PNG 的微小差别替代直接数值判断。
最终 Python 回归 380 passed，8 条已有依赖警告；新增四项科学检查涵盖来源身份、
禁止外推、共享光谱的独立留出预测、任意通道幅度消除、片边对齐及有效样本统计。

运行入口是 `experiments.camera_response_sensitivity` 和
`experiments.report_camera_sensitivity`。沿用原生半尺寸及校正后的保留输入，
没有再次开发 RAW，也没有为本次比较触发全尺寸开发。计算代码和来源元数据
属于仓库；照片、数值响应、校准、LUT、图表和报告页面均不加入 Git。

实验提供敏感度证据，没有完成独立真实负片颜色标定。未将任一候选替换为
桌面应用默认，也未据此宣称哪组结果就是原场景的真实颜色。
