# 三条管线的默认显示与外部对照

2026-10-27，Issue #2。反转片和光学放大默认采用色度转换，APD 默认采用官方
ACES 2.0 SDR 100 nits。此修改不重新标定材料、曝光、观看增益或相纸滤色。

## 执行路径

| 流程 | 物理及输入转换 | 默认显示 |
| --- | --- | --- |
| 反转片 | 场景反射谱 × 拍摄光 → 胶片曝光与显影 → 透射谱 × 观看光 → 观察 XYZ | XYZ D65 → 目标 RGB 矩阵 → 目标传递函数 |
| APD | 负片透射谱 → 标准 APD → Dmin／连续 ADX → 锁定的胶片输入转换 → ACES AP0／D60 | 官方 ACES 2.0 目标视图 |
| 光学放大 | 负片透射谱 × 放大光 × 滤色透射谱 → 相纸曝光与显影 → 反射谱 × 观看光 → 观察 XYZ | 与反转片相同的色度转换 |

光学放大不再计算无用的 APD／ADX 中间量。Status M→APD 仍只用于负片材料的
标定目标处理，不在光学印相途中增加数字负片输出。

色度转换由 OCIO 的 `DISPLAY - CIE-XYZ-D65_to_*` builtin 执行，不经过 AP1、
OpenDRT 的显示 LUT 或其编码表。支持 sRGB、Display P3、黑位为零的 Rec.1886。
原始观察 XYZ 与光谱保留；当前 D50 参考白适应约定及观看增益不变。最终编码
裁切到 0–1，不宣称屏幕可以精确显示所有实体颜色，也未加入感知色域映射。
OpenDRT 和 ACES 可作为反转片、相纸的另选创作外观，不能把它们称为纯色度复现。

## 独立检查

脚本 `experiments/validate_pipeline_defaults.py` 使用八张完整高光谱场景，
不导入历史模拟程序、相机配置或私有代码。显示码差是逐像素 RGB 最大通道差乘
255，输出先限定到 0–1；不是实物胶片测量误差。

1. 反转片和相纸：独立的 CIE 表读取、梯形积分、Bradford 矩阵、目标 RGB
   数值矩阵和分段 sRGB 公式，与应用的完整默认输出比较。
2. APD：独立对透射谱积分标准响应，计算连续 ADX 码值，调用 OCIO 的
   `ADX16_to_ACES2065-1` builtin，再直接调用官方 ACES 2.0 配置视图。
   不经过本项目的 ADX-to-ACES 代码或 XYZ 显示桥接来生成期望值。
3. E100：读取文稿保存的 D55 曝光 kernel，用当前重新拟合的材料与 C++ 核重放
   八张场景、−1／0／+1 EV，与历史透射结果、XYZ 和线性 RGB 数组比较。
   这是独立保存结果的回归，不是重新宣称 D55 kernel 是当前 D65 配方。
4. 相纸：读取历史相纸 XYZ，施加文稿记录的观察密度标量后，经新显示链重放。
   再将当前相纸模型的完整输出与文稿比较，分别记录显示重放和材料模型差异。

| 检查 | 八场景中的最大码差 |
| --- | ---: |
| 反转片默认管线与独立色度公式 | 0.002501 / 255 |
| 相纸默认管线与独立色度公式 | 0.002492 / 255 |
| APD 默认管线与独立积分／OCIO builtin／官方 ACES 2.0 | 0.002672 / 255 |
| E100 D55 条件重放，含三档曝光 | 0.111323 / 255 |
| 文稿相纸 XYZ 经新显示链重放 | 0.018355 / 255 |

E100 重放的原始 XYZ 最大绝对差为 2.981×10⁻⁸，符合历史 float32 数组的存储
精度。显示差还包括原参考 RGB 矩阵数值与 OCIO builtin 的差异。新默认 E100
保留 D65 曝光标定；与文稿的 D55 模型相比，每张场景均有至少 99.65% 像素在
2/255 内，但不能将其描述为完全相同的拍摄条件。

## 没有通过的比较

相纸的显示步骤通过上述检查，不代表材料模型通过验证。当前模型使用原厂
密度曲线与有效染料基，文稿还使用实测成品反射谱约束、另一组滤色形状、
不同的曝光标定和观察亮度处理。scene43 当前相纸结果对文稿的平均码差
21.646、P95 51.385、最大 56.327；只对齐负片 D55／−0.6 EV 后仍为平均
14.033、P95 26.417、最大 31.880。该比较不是相同纸模型的精度排名，也不构成
当前模型正确的证据。没有用逐图配平或末端调色掩盖这项差异。

APD 按文稿的 D55／−0.6 EV 重算并共用 ACES 2.0，scene43 平均码差 1.630、
P95 3.611、最大 4.025，约 63.35% 像素在 2/255 内。材料谱、片基、有限波段和
密度拟合方式仍有差异；标准输入／显示实现通过检查，不等于当前负片模型已
复现文稿或真实胶片。完整色彩的实测胶片曝光与透射谱验证仍缺失。

## 65³ 导出

三条新默认管线各生成一份 65³ 显示 CUBE，完成文件读回、独立 OCIO 执行和
原生／Python 插值检查。文件完整性均通过。网格误差与光谱近似分开记录：

| 流程 | 连续 RGB 模型与 LUT：2/255 内 | RGB 近似与光谱模型：2/255 内 |
| --- | ---: | ---: |
| 反转片 | 94.94% | 32.14% |
| APD | 99.44% | 29.27% |
| 光学放大 | 96.63% | 39.49% |

前列使用固定 38,081 个 RGB 开发样本；后列使用 1,560 个测量光谱输入，扩展
为三档曝光共 4,680 点。两组抽样不是同一分布，也都不是新的盲测数据。
反转片与相纸的 65³ 插值尚未达到 99% 参考线。当前普通 RGB 的平滑光谱先验
误差更大，不能把 APD 的 99.44% 插值通过率写成胶片模拟准确度。
用户仍可选择网格并查看实际误差；本次不更改质量阈值或掩盖超标结果。

复现命令：

```sh
python -m experiments.validate_pipeline_defaults \
  --output artifacts/pipeline-default-review --exports
```

本地输出包括源文件哈希、逐场景数值、同一 sRGB 目标下的对照图和三份冻结
LUT。输入及派生资产保留本地，未经权利审核不发布。原始文稿、旧导出及用户
曝光／材料设置不由比较脚本改写。
