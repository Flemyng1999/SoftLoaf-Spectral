# 生成胶片 LUT 需要哪些输入

生成 LUT 不需要先打开照片。需要先保存一套完整配方：输入颜色的含义、
RGB 到光谱的近似、材料数据、曝光与成像条件，以及 LUT 的输出定义。
程序在声明的输入范围采样，逐点执行同一套光谱计算，再将结果写成 LUT。

普通 RAW、相机 DCP 和测试照片用于应用与检验。它们不是通用胶片 LUT
生成时必须提供的数据。当前可运行的参考是 E100；下表中的两条 5207
流程仍是接口要求，不能据此视为已经实现或验证。

## 三条流程共同的输入

| 节点 | 必须保存的输入 | 用户通常怎样提供 |
| --- | --- | --- |
| 颜色输入 | 原色、白点、编码、相对亮度与曝光尺度、有效范围、负值和超范围处理 | 选择输入空间和曝光约定；当前实验为 ACEScct AP1/D60 |
| 光谱估计 | 重建方法和版本、先验数据或基函数、假定照明、正值约束、超出模型范围的处理 | 选择有明确适用条件的预设；不能从 RGB 唯一恢复真实光谱 |
| 拍摄照明 | 光谱功率分布 SPD、幅值约定、波长范围 | 选光源预设或导入曲线；单独的色温值不足以代替 SPD |
| 胶片感光 | 三层线性感光响应、能量或光子响应约定、层间相对尺度 | 选择材料配套数据，或导入带单位的曲线 |
| 显影与定标 | 特性曲线、密度测量响应与几何、显影状态、曝光原点、从层曝光到染料系数的模型及冻结参数 | 选择材料预设并完成拟合；仅有三条特性曲线不能唯一确定所有颜色响应 |
| 染料与片基 | CMY 光谱密度、系数单位、片基和灰雾是否已计入 | 使用配套材料记录；已包含的片基不能再叠加 |
| 输出接口 | 输出量与单位、白点、观察者、Y 的尺度、适应方法及其执行位置 | 选已验证接口；当前内部 LUT 输出相对观看 XYZ D65，不是显示 RGB |
| LUT 构建 | 输入范围、网格、整形曲线（如有）、采样或系数拟合方法、插值、边界处理、精度及版本 | 使用通过检验的导出规格；33³ 本身不保证某种误差 |

反射率模型中，胶片入射谱由估计反射谱乘拍摄 SPD 得到，再积分各层有效
曝光。方法若直接估计入射谱，就不能再次乘同一光源。这项约定属于光谱
估计节点，须随配方保存。更换假定照明不等于把原 RAW 场景真实地重新照明。

所有曲线还需带波长 nm、采样位置、覆盖范围、插值和缺失波段处理、单位、
归一化方式、来源版本与哈希。积分必须包含波长权重。对数感光响应先转换
为线性值；量子效率与能量 SPD 配对时须处理光子转换。不同通道不能随意
分别归一化后仍沿用原定标。

密度到透射率采用 `T(λ) = 10^(-D(λ))`。Status A 等测量密度与染料系数
是两种量；其间需要材料模型和拟合。缺少的化学作用、散射或光谱尾部须
说明为模型限制，不能用拟合误差小来代替实物色彩验证。

## 各流程还需要什么

| 流程 | 后续节点 | 必须保存的输入 |
| --- | --- | --- |
| 5207 APD | 材料内部密度接入，默认隐藏 | 原始 Status M 定义、绑定片种的 3×3 矩阵与偏置、片基约定、拟合域、残差与来源；替换材料自动匹配，不增加用户节点 |
| 5207 APD | 标准 APD 密度 | SMPTE ST 2065-2:2012 原始谱权重、完整波段、归一化、测量定义及数据版本；已读技术说明中的历史表，规范核验与运行时接入待完成 |
| 5207 APD | 标准输出 | Dmin／片基密度、通道增益、所用 APD 浮点／ADX 编码约定、锁定版本的 APD/ADX-to-ACES 及其 XYZ 桥接；现已接入本地参考计算，保留材料近似条件 |
| 5207 光学放大 | 放大与滤色 | 放大 SPD、滤色片透射谱及滤色量、放大曝光 |
| 5207 光学放大 | 相纸 | 分层感光、曝光到显影结果的模型及系数、反射与散射模型、纸白和适用冲洗条件 |
| 5207 光学放大 | 成品观看 | 观看 SPD、观察者、亮度尺度及白点适应 |
| E100 透射观看 | 灯箱观看 | 观看 SPD、观察者、亮度尺度及白点适应；无负片反演与相纸节点 |

彩色负片直接按标准 Academy Printing Density（APD）输出，不加入翻拍光源、
相机响应或翻拍定标。标准权重须冻结；调整后只能称自定义密度。缺少标准
所需波段时，不得补零后仍称标准符合。DCP 只处理原数字照片的相机输入。

APD 浮点密度与 ADX 编码不同，ADX 规范为 SMPTE ST 2065-3:2012。
Status M → APD 接入默认自动执行，放在材料内部；只在专业详情查看
和导入校准，不提供主流程开关。已由透射谱积分得到的 APD 不重复执行
矩阵。原始曲线、转换后的标定目标与拟合方法都须保存，见
[APD 与 ADX](apd-adx.zh-CN.md)。

标准输出参考限定为 [aces-core v1.2（2019）](https://github.com/aces-aswf/aces-core/tree/v1.2)，
还需读取和验证原 CTL、依赖与精确版本，不能用 RGB 反相替代。当前负片
仅保存含空缺数据项的草案，不生成 APD 数值或 LUT。数量与资料来源见
[方法](science-and-pipelines.md#negative-apd-and-standard-output)。

所有需要拟合的状态须先保存，再逐点应用。按每张照片重新找黑白点、自动曝光、
局部色调、颗粒、光晕和空间邻域处理不能藏进静态 3D LUT。

## DCP 与 OpenDRT 放在哪里

```text
应用：RAW → RawTherapee 解码、白平衡、DCP/矩阵 → 核验输出并接入声明空间
     → 胶片 LUT → OCIO 白点与尺度桥接 → OpenDRT → 文件编码

生成：声明空间的颜色采样 → 固定光谱估计 → 胶片与所选成像流程
     → 声明输出 → 采样或拟合 3D LUT → 文件读回检验
```

RAW 解码需声明黑白电平、去马赛克、通道增益、白平衡和曝光处理。DCP
需记录所用照明、矩阵、HueSatMap、曝光项及是否使用风格表和色调曲线。
改变 RAW 的配置通常重处理输入，不改变通用胶片 LUT 的材料配方。
没有传感器光谱响应仍可通过匹配 DCP 使用 LUT，但颜色表征误差须单独检查。

内部胶片 LUT 不含 OpenDRT。其后显示处理需固定 OCIO 配置和依赖哈希、
输入桥接、Display、View、OpenDRT 版本和外观、目标亮度及实际输出编码。
若导出包含显示处理的一体 LUT，这些也成为生成输入；再次应用时不重复
执行 OpenDRT。界面不能给缺少实现或材料数据的参数提供虚构调节。

## 当前 E100 参考的具体约定

- 输入 ACEScct AP1/D60；先解码到线性 AP1，采用最小一阶差分光谱先验，
  L2 项为 1e-8，重建负波段置零，不设反射因子上限。
- 拍摄光 D65，曝光积分 400–720 nm、10 nm；E100 的三层感光、特性曲线、
  CMY 密度谱配套使用。密度系数以已有有限波段 Status A 权重重新拟合，
  片基吸收包含于有效系数中。
- 平坦 18% 灰作为曝光锚点，按 D50 视觉透射 Y=0.1 定位。这是相对模拟
  约定，不是实测相机 ISO、快门或胶片绝对曝光校准。
- 观看光 D50，400–700 nm、2 nm，CIE 1931 2°；固定观看增益 1.8，有限
  波段白经 Bradford 适应到 D65，输出相对 XYZ。
- 内部 LUT 与 OpenDRT 分开；实验后接 OpenDRT v1.0.0 Default 和已核验的
  标准 sRGB 文件编码。详细包版本与哈希见[实验报告](../research/hsi-raw-lut-comparison.md)。

这些是该参考的配方输入，不是其他胶片必须沿用的物理常数。修改材料、
光谱先验、模拟照明、定标或观看条件后，重新生成受影响的 LUT。

## 验收与交付

LUT 规模由用户选择，65³ 为默认建议。99% 的像素三个标准 sRGB 通道绝对差
均不超过 2/255 是参考线，未达到仍可导出。连续码值与实际 8 位量化分别
检查；展示文件体积、样本数、平均、P95、最大误差、逐图与
汇总结果、超范围比例。分别报告“LUT 相对同配方连续计算”的插值误差，
和“RAW/DCP/LUT 相对直接光谱计算”的总误差。前者通过不代表后者通过。

检验需要独立于系数拟合的样本，包括灰阶、近黑、饱和色、负值、输入边界
和超范围情况。开发照片上的通过率不构成整个颜色立方体的误差保证。
保留 float64 参考，用实际执行库读回导出文件并比较。曲线来源、许可与
发布权限也是交付条件；当前受限材料和生成资产仍留在本地。
