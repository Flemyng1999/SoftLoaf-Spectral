# 5207：旧参考图与当前应用为何不同

2026-10-27，针对 scene43 橙紫花朵，读取文稿参考分支保存的 APD、ADX16、
ACES2065-1 与显示 RGB 数组，和当前应用逐段比较。没有导入旧产品程序、相机
配置或整卷定标实现，也没有改动用户配方或应用默认值。

旧参考位于本机 `video/assets/experiments/apd-standard-reference-v1/`；
该目录的内容是本次比较证据，不是当前实现的规范或材料准确度证明。

## 条件没有对齐

| 条件 | 文稿参考第 2 列 | 当前截图的 5207 配方 |
| --- | --- | --- |
| 拍摄照明 | CIE D55 | D65 |
| 平坦 18% 灰的模型曝光位置 | −0.6 Camera Stops | 0 Camera Stops |
| 显示变换 | ACES 1.0 - SDR Video，ACES 1.3 配置 | OpenDRT Default |
| 输出 | sRGB | sRGB |
| 胶片积分范围 | 402–788 nm / 2 nm | 360–730 nm / 2 nm |
| 中性拟合 | 保留原片基，拟合 Status M 净密度增量 | Status M→APD 目标拟合，并校准模型片基 |
| ADX16 | 四舍五入为 16 位码值 | 浮点码值，不取整、不裁切 |

当前的“胶片曝光 0 EV”与旧实验的名义曝光不是同一模型曝光位置。
这 0.6 挡差异不能靠匹配显示变换消除。图中第 1 列另有原场景呈现约定，
文稿也明确将它作为风味背景；它不是与当前 A 完全相同的显示链。

## 重放和条件隔离

所有显示差值先裁切为最终可显示的 0–1，再逐像素取 RGB 最大绝对差，乘以
255。表中的码差不是实测胶片准确度，也不是 LUT 插值误差。

| 比较 | 平均最大通道码差 | P95 | 最大值 |
| --- | ---: | ---: | ---: |
| 保存的旧 ADX → 当前转换代码 → 同一旧 ACES 显示，与旧参考比较 | 0.000096 | 0.000228 | 0.002067 |
| 同一旧 ACES 数据，只把显示换成 OpenDRT | 5.138 | 13.472 | 17.214 |
| 当前应用默认条件，与旧参考比较 | 14.940 | 30.442 | 37.522 |
| 当前模型，改用 D55、−0.6 EV、旧 ACES 显示 | 1.787 | 4.165 | 4.762 |

ADX 取整与保留浮点的差异单独测得最大 0.024851/255，解释不了图中的大差异。
当前 192 像素宽预览与全分辨率直接计算的同位置像素差为 0，未发现试片误走
RGB 光谱近似、LUT 插值或缓存替换导致的偏差。

将两套模型都改用 ACES 2.0、并对齐上述拍摄条件后，平均码差 1.630、
P95 3.611、最大 4.025/255。仍只有约 63.35% 像素在 2/255 内，不能宣称两个
模型已经等效。对应净 APD 的 R/G/B RMS 差为 0.008546 / 0.006873 / 0.002947 D。
剩余差异位于不同材料资料、拟合方式、片基与有限波段约定，尚不构成哪套模型
更接近真实胶片的证据。

因此，本次没有把当前模型调色至贴合旧图，也没有把主配置降回 ACES 1.3。
比较时应先确定同一曝光、照明和显示条件，再讨论材料模型的残差。

## 当前重算与回归（仅 ACES 2.0）

按用户后续要求，当前实现已移除旧 ACES 显示运算。上面的旧显示比较数值作为
历史排查记录保留；当前比较脚本从已保存的 ACES2065-1 输入重算 ACES 2.0，
不执行旧 ACES 显示，也不再生成旧显示配方。

```sh
python -m experiments.compare_5207_reference \
  --reference video/assets/experiments/apd-standard-reference-v1 \
  --output artifacts/5207-reference-comparison-aces2
```

输出包含数值记录、逐项条件图和可在工作台打开的对照配方：

- `aligned-aces2-recipe.json`：当前材料，D55 / −0.6 EV / ACES 2.0。

该文件经过当前配方校验。它对齐比较条件，使用的仍是当前材料模型。
源数组、参考报告和高光谱场景的哈希写入生成的 `report.json`。
原 PNG 与其保存的浮点数组按原始 float32 量化方式读回一致。

可选本地回归用玫瑰、蕨叶、橙紫花三张已保存 ADX 和 ACES 数据，分别接入同一
ACES 2.0 显示，最大码差要求低于 0.01/255。这仍不验证胶片曝光到彩色透射谱的
物理准确度。旧配方载入时自动迁移，不作为旧显示运算的入口。
