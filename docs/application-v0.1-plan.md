本文保留早期设计／执行记录；5207 与相纸已接入计算，当前状态以[流程核查](5207-pipeline-audit.zh-CN.md)为准。


沿用已确认的固定节点界面。Issue #2，继续使用当前任务分支，保留已有修改。

## 架构

C++17 动态库负责逐点数值计算：AP1 RGB 光谱估计、胶片曝光、特性曲线插值、
染料透射、观看积分、XYZ 适应，以及 ACEScct 解码和四面体 LUT 插值。
用稳定的 C 接口连接当前 Python 服务；Python float64 保留为独立校验路径。
材料中性拟合和已锁定的 OCIO / OpenDRT 仍使用现有实现。

macOS 使用 AppKit / WebKit 窗口承载已确认的界面。它启动并管理本地服务，
退出时回收服务，提供文件选择和下载保存。此开发版依赖本机 Python 环境及
本地材料数据；不把依赖开发目录的应用称为可分发安装包。计算库不依赖 macOS。
这一选择保留已完成的界面与参考程序，避免此时引入 Qt 并重写图表和交互。

## 本次范围

1. 建立 CMake 工程、C++ 内核、Python 绑定，测试数组布局、边界、异常和线程安全。
2. 接入工作台的预览和 LUT 生成；记录实际内核、ABI 和数据条件。
3. 建立应用入口、启动检查和原生窗口。试片支持 PNG / JPEG 及内嵌 ICC，
   明确其为已渲染 RGB，不能作为已验证的相机 RAW 交接。
4. 导出与当前配方一致的全尺寸 PNG，附配方及输入解释；验证文件读回。
5. 运行完整现有测试，比较 C++ 与 Python 的中间光谱和 XYZ，并实际打开桌面窗口。

## 边界与验收

E100 可计算；5207 APD 和光学放大保持可保存的未实现草案，不能生成伪结果。
RAW 解码、DCP / RawTherapee 桥接仍待验证。两个采样库保持独立；本次保留
已有平滑先验，不静默换成实验候选模型。LUT 规模与误差展示沿用现有行为。

验收包括：本机可构建和打开应用；材料节点可编辑；C++ / float64 的曝光、
透射谱、观看谱和 XYZ 在明确容差内一致；导入的试片可预览并导出同尺寸图像；
导出配方和数值文件可读回；关闭窗口不会留下它启动的服务。外部数据不打包发布。

## 执行记录

四个实现步骤已接通。增加了已应用配方与对照的自动恢复，保存采用原子替换、
进程间文件锁和版本检查；退出前等待暂存完成，未应用草稿需要用户处理。
Python 中性拟合和 OCIO 显示继续作为混合应用的一部分，没有改写成未经校验的新算法。

实际在界面中将 E100 红通道感光谱整体乘 1.05，重新拟合、应用并生成 65³
CTF 包。38,081 个插值检查样本中，C++ / Python 最大输出差 2.22e-16，
OCIO / float64 最大输出差 4.67e-7。显示后连续值 99.07%、8 位值 99.37%
处于 2/255 内；这不是对真实胶片或 RGB 光谱估计的精度保证。

原生文件选择、照片包保存、配方 JSON 保存均已操作并读回。512×320 试片
导出保持原尺寸及 sRGB ICC，退出原生窗口后其服务进程已结束。

最终构建通过 1 项手算 C++ 测试、105 项 Python 测试和 9 项 JavaScript 状态
测试。macOS 二进制最低系统目标已读回为 14.5；实际未在其他系统版本验证。
原生窗口重启后保留三份配方与已有对照。独立界面检查没有警告或错误日志。
