# 光谱与曲线的 CSV 输入

自定义曲线只接受 `.csv`，UTF-8 编码，英文逗号分隔，第一行为固定表头。
一行一个采样点；数字可用小数或科学计数法。不能省略列名、交换通道、
使用分号、空值或 JSON。不要添加百分号、单位文本或自动补齐缺失波段。

| 数据 | 第一行 | 横轴与数值约定 |
| --- | --- | --- |
| 观看光源 | `wavelength_nm,value` | nm；相对能量 SPD，完整覆盖 400–700 nm |
| 胶片感光谱 | `wavelength_nm,R,G,B` | nm；线性相对能量响应，完整覆盖 400–720 nm |
| E100 特性曲线 | `log_exposure,R,G,B` | log10 相对曝光；Status A 密度 D |
| E100 染料谱 | `wavelength_nm,C,M,Y` | nm；光谱密度 D，完整覆盖 400–700 nm |

5207 与相纸使用以下补充约定，表头中的通道顺序保持相同：

| 数据 | 第一行 | 横轴与数值约定 |
| --- | --- | --- |
| 5207 特性曲线 | `log_exposure,R,G,B` | log10 相对曝光；Status M 密度 D，随曝光递增 |
| 5207 染料谱 | `wavelength_nm,C,M,Y` | 360–730 nm；扣除 D-min 的净光谱密度 D，可为负 |
| 5207 片基谱 | `wavelength_nm,value` | 360–730 nm；光谱密度 D |
| Ultra Endura 感光谱 | `wavelength_nm,R,G,B` | 360–730 nm；线性相对能量响应 |
| Ultra Endura 特性曲线 | `log_exposure,R,G,B` | log10 曝光；Status A 密度 D，随曝光递增 |
| Ultra Endura 染料谱 | `wavelength_nm,C,M,Y` | 360–730 nm；有效反射光谱密度 D |
| 放大光 | `wavelength_nm,value` | 360–730 nm；相对能量 SPD，按原 3200 K 光度归一化 |
| 理想滤色谱 | `wavelength_nm,C,M,Y` | 360–730 nm；每单位 CMY 参数的吸收密度 D |
| 相纸观看光 | `wavelength_nm,value` | 360–730 nm；相对能量 SPD |

Status M→APD 在材料拟合时自动处理，不需另导入已转换的曲线。APD 标准权重
和固定 ACES 变换不开放任意改写。厂商只给出有限曲线时，用户需明确自己的
波段延伸假设，不能把未测区域当成实测数据；模板包含本地模型的声明范围。

横轴严格递增，各列等长，曲线值有限。除 5207 扣底染料谱外，各值须非负。
5207 导入标记为 `net_spectral_density`，与片基及有效染料量合成后的绝对密度
必须始终非负。应用前检查各染料量独立变化的整个范围，不能只靠中性拟合。
片基、滤色谱、相纸和 E100 染料谱仍不接受负值。E100 特性曲线的密度随曝光
递减或持平。光谱最多 8192 点，特性曲线最多 1024 点，文件最多 400 KB。
不把对数感光度当作线性响应，也不把 Status M 密度当作 E100 Status A。

在对应曲线页点击「下载 CSV 模板」，取得当前完整曲线及其正确表头。
在外部编辑或准备自己的数据，再用「导入 CSV」替换。图表始终只读。
导入先做格式与覆盖检查；点击「应用修改」后再校验材料相容性、重新拟合
并更新结果。失败时不替换已应用的配方。文件名及 SHA-256 随配方记录。

内置光源与材料仍可选择。「日光色温」是 CIE D 系列模型参数，采用
4000–10000 K 滑块，6500 K 保持原 D65。它生成标准日光模拟谱，不代表
仅凭温度就能恢复某次实测太阳光谱。拍摄光源保持与原 D65 相同的有限波段
光度 Y，不按不同色温重新拟合胶片灰锚点；A 原始参考的照明保持不变。
计算方法见 [Colour 日光模型文档](https://colour.readthedocs.io/en/v0.3.16_b/generated/colour.sd_CIE_illuminant_D_series.html)。

配方 JSON 仍用于保存与恢复整份配方；它不作为单条曲线的导入格式。


新版放大光路的隔热／镜头 CSV 使用 `wavelength_nm,value`，CMY 滤片使用
`wavelength_nm,C,M,Y`，单位均为透射率 fraction，范围 0–1，要求覆盖
360–730 nm。纸底 CSV 使用单值表头，单位为光谱密度 D。它们不能与旧版
吸收滤色的 CMY 密度互换；应用按所选光路明确解释。纯零纸底和阻断透射
曲线是有效输入，不被误当作空白光源。详见[光路更新](printing-optics.zh-CN.md)。
