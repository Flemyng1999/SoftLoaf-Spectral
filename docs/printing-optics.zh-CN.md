# 光学放大光路更新

2026-10-28，Issue #2。新版 `spectral-v2` 独立计算放大灯、隔热玻璃、镜头和
二向色滤片，再曝光相纸。负片仍直接拟合 Status M；APD 仅属于另一个正相分支。

## 使用

新建光学放大配方默认使用新版光路。现有配方补记为 `legacy-v1`，保留原来的
3200 K 光源、相纸染料形状吸收滤色和常数纸底模型，不静默更改成片。

在“放大照明”的“放大机”选择器可明确切换。切换会填入该光路的内置起始
曝光／滤色，可撤销；负片材料、拍摄光和胶片曝光不变。已有自定义相纸保留。
新配方与切换的起始设置按内置材料及其参考拍摄光生成，改变拍摄条件后不会
在后台重新平衡当前照片。

“光路与预闪光”内可选择或旁路隔热玻璃与镜头，并设置预闪曝光和独立滤色。
镜头默认旁路，预闪默认关闭。参考 Canon 摄影镜头曲线不是实测放大镜头，
选择它仅供比较。用户可在对应光谱页签导入自己的 CSV。

相纸节点增加白底光谱页签，允许导入最低光谱密度。仍只接收 CSV，不增加
手动画曲线。光路透射率的表头为 `wavelength_nm,value`，CMY 滤片为
`wavelength_nm,C,M,Y`，数值为 0–1；纸底使用单值表头，数值为光谱密度 D。
计算数据须覆盖 360–730 nm；图表显示范围延续既有规则。

## 计算

采用独立实现的部分插入模型。每个 CMY 控制量 d 对应未滤光比例 q=10^(-d)，
有效透射率为 q+(1-q)T；三路相乘。这里的控制量不是实测放大机刻度或材料厚度。
旧配方仍采用 10^(-CMY 密度谱 × 控制量)，不能把两种模型的同一数值当作等效。

新版相纸主曝光：

    H_main(λ) = T_negative(λ) × E_lamp(λ) × T_heat(λ)
                × T_lens(λ) × T_CMY(λ) × 2^print_EV

预闪使用相同灯／光路、独立 CMY 控制和固定片基透射率，构造独立于图像内容的
附加曝光谱。其强度以未乘主放大 EV 的名义光源为基准，范围 0–1；相纸总曝光
为 H_main+H_preflash。它不是显示端抬黑，也不会改变负片或再次曝光胶片。
这与上游将总曝光再整体乘放大曝光的参数约定不同，不能直接交换预闪数值。

波长积分包含梯形宽度。总曝光在进入现有 C++ float64 材料内核前相加，因此
曝光、显影和反射率仍使用同一数值内核；保留独立 NumPy 参考。

自定义灯光 CSV 明确作为光路前的相对能量 SPD；若它已经包含 KG3 或镜头，
需把对应组件设为“无／已包含在光源中”，避免重复相乘。替换 SPD 的光度尺度
沿用已声明的参考归一化，不假定它提供绝对 lux-second。

新版以固定虚拟 18% 平坦反射率，在内置材料参考拍摄光下求一次起始滤色和
放大曝光，使三层相纸相对曝光到达 [1,1,1]。它不分析照片或片卷，不动态拟合，
也不是完整色彩准确度证明。13 个内置负片材料均能在规定控制范围内达到该
起始目标，最大 log10 层曝光残差小于 6×10^-12。

## 资料与纸底边界

数值来源固定到 spektrafilm 提交
`3bb2c2d2801ff68b92019cf1dbcbb133d60832bc`：

- Schott KG3 数字化透射曲线；原始链接指向 Newport，玻璃厚度未明确，不能
  宣称是任意实物 KG3 的标定。
- Edmund Optics CMY 数字化透射曲线，原注释指向 50 mm 圆形滤片资料。
- 可选 Canon 24mm f/2.8 IS 摄影镜头透射曲线，原始来源为 Lensrentals。
- Ultra Endura 加工模型的最低密度谱形状；没有将其完整相纸模型或已解混
  特性曲线冒充本项目的原厂 Status A 曲线。

原始文件保持本地并校验 Git blob／SHA-256；公开身份记录见
[data/printing-optics-manifest.json](../data/printing-optics-manifest.json)。
光谱重采样先排序、平均重复波长，再线性插值。滤片短于其约 380 nm 原始范围
的部分，以及纸底 380 nm 以下部分，采用端点保持并记为尾部假设，不是测量。
百分比透射率先转换为 0–1；KG3 原文件已经是比例，不重复除以 100。

纸底保留上游加工谱形状，只施加一个公共密度偏移，使其最低密度与本项目
原始 Status A 目标兼容，随后重拟合相纸有效染料量。没有逐波长裁切，也没有
把这一步称为实测白纸。当前纸底范围约 0.04956–0.09362 D；原始中性曲线的
最大回算残差为 0.00754 D。相纸内部散射、荧光增白与曝光配对实测仍未建立。

导出保留 SoftLoaf Spectral、Yangming Feng and contributors、光路版本、实际
组件、控制定义、预闪参数、来源和哈希。使用上游加工数据时附原许可与
CHANGELOG.txt，保留 Andrea Volpato 和 CC BY-SA 4.0；滤片厂商原始资料的
分发权限仍单独记录，未把本地可用解释为完成公开发行审核。

## 验证结果

- 修改前保存的 24 色块结果与旧版管线逐项比较，显示 RGB 最大变化为 0。
  反转片和 APD 原结果同样保持不变。
- 新旧放大采用完全相同的负片透射率；更改光路或预闪不改变负片材料。
- 独立逐波长积分核查部分插入和预闪相加；C++ 与 NumPy 参考在浮点精度内一致。
- 对新版 24 个 BabelColor 输入的相纸输出，用 colour-science 独立进行 D50／
  CIE 1931 2° 积分。与应用观看 XYZ 最大绝对差为 9.62×10^-6。
- 新版 65³ CUBE 文件读回一致，独立 OCIO 与 float64 输出最大差约 1.89×10^-6。
  这份默认配方的 38,081 点抽样中，连续值误差在 2/255 内约 96.56%，8 位结果
  约 97.12%，未达到 99% 参考线；应用如实显示结果，仍允许导出或改选网格。

这些检查覆盖来源解释、积分、数值实现和文件执行，不能代替真实负片与相纸的
有色色块／成片测量。旧新成片比较见本地
`artifacts/printing-optics-review/printing-optics-comparison.png`；原配方、新配方、
导出文件和 verification.json 记录在同目录。


## 可选相纸与原厂条件

2026-10-28，在相纸节点和试片调整栏增加独立相纸选择。保留原有 Ultra Endura，
新增 Endura Premier、Ektacolor EDGE、ROYAL Digital 和 Endura Premier Metallic。
切换仅替换相纸快照，保留负片、放大光路、滤色、曝光和观看设置；可以撤销。
已有配方不跟随目录更新。无原始曝光条件的资料不冒充完整光学放大测量。

| 相纸 | 原厂文档 | 特性曲线条件 |
| --- | --- | --- |
| Endura Premier | E-4070，2017-12，p4–5 | 0.5 s；RA-4，35°C / 45 s；Status A |
| Ektacolor EDGE | E-7020，2019-04，p3–4 | 曝光时长未注明；RA-4，38°C / 45 s；Status A |
| ROYAL Digital | E-7021，2019-04，p3–4 | 曝光时长未注明；RA-4，38°C / 45 s；Status A |
| Endura Premier Metallic | E-4071，2013-03，p4–5 | 0.5 s；RA-4，35°C / 45 s；Status A |

四款均由各自原厂 PDF 矢量图独立提取感光谱、特性曲线和 CMY 密度谱，未使用
spektrafilm 的加工相纸曲线替代。原始顶点、PDF 坐标、曲线标识与映射坐标均保留，
并生成原图覆盖检查。2 nm 重采样不是新增测量分辨率；图表使用原始矢量详情。
感光谱保留到 750 nm，当前负片与相纸曝光计算仍限于 360–730 nm；730 nm
以外的感光尾部未进入当前模型。CMY 在原图 400–700 nm 以外使用自身端点延伸。

新材料使用自身原始感光谱冻结曝光分母，以既有虚拟 5207 / D65 / 18% 灰片和
3200 K 放大灯作为共同软件参考。初建时求 D50 Y=0.1 的相纸曝光原点，此后
CSV 替换感光谱或特性曲线不重新标定。它不是原厂放大曝光、ISO 感光度标定，
也不是按当前照片自动曝光或调白。

纸白使用自身最低 Status A 密度的常数模型，不借用 Ultra Endura 纸白。
荧光、散射和已知曝光对应的成品反射谱尚无实测。Metallic 只计算颜色近似，
不模拟金属纸基的方向性反射。EDGE 与 ROYAL 原厂公布的感光谱和染料谱相同，
不人为增加色彩差异；两者保留各自公布的特性曲线。

资料身份见 `data/paper-presets-manifest.json`。Fuji DPII AF3-212E 旧版虽有三类
曲线，但注明激光曝光、CP-48S 和相对曝光轴，故保留为参考，不混入光学放大
菜单。新旧 DPII 文档不交叉拼成一个原厂材料。缺少特性曲线的 Maxima、Supreme
及 Type CA 不填入其他相纸曲线。

`experiments/verify_paper_presets.py` 对照原厂原始顶点，并验证四款 VISION3 与
四款新增相纸的 16 种组合，每种使用 BabelColor 24 色块和 −2 / 0 / +2 EV。
检查反射率物理范围、C++ 与 NumPy float64、独立 D50 / CMF 积分和 sRGB
矩阵编码，另读回四份 65³ CUBE 并使用独立 OCIO 执行。中性拟合最大残差约
0.0030–0.0043 D；保留原始顶点重投影最大约 0.0142 D。数值、原图与文件检查
均不代表真实彩色相纸的曝光—成品准确度。
