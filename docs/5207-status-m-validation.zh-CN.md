# 5207：Status M 材料拟合与两条输出管线

分别记录测量、显影、放大与观看条件，见[默认光源与相纸条件](5207-d55-and-paper-conditions.zh-CN.md)。
下文的 D65 默认场景结果保留为 /3 记录。

2026-10-27，Issue #2，模型 `5207-paper-reference/3`。

Status M 用于匹配 Kodak 原厂的测量曲线，确定材料的曝光—有效染料量关系。
APD 用于负片标准输出，经 ADX 编码和输入变换进入 ACES。二者都是密度定义，
不是染料含量或 RGB 色彩空间。**材料拟合不再使用 APD 权重或 Status M→APD 矩阵。**

## 现在的顺序

材料标定：原厂片基与 CMY 净密度谱 → 合成透射谱 → Status M 加权积分 →
匹配 Kodak 原始 Status M 特性曲线 → 冻结曝光与有效染料量曲线。
片基对齐也使用 Status M，随后对整个独立染料量范围检查总密度非负。
这仍是固定谱形的三层近似，没有据此声称染料浓度或层间化学已被测得。

两条管线共享同一份负片材料和透射谱：

- **APD 输出：**场景曝光与显影 → 负片透射谱 → APD 及同定义的模型 Dmin →
  ADX16 浮点码值 → 锁定的标准负片输入变换 → ACES2065-1/AP0/D60 →
  XYZ/D65 接口 → 默认 ACES 2.0 显示。
- **光学放大：**场景曝光与显影 → 负片透射谱 × 放大光 × 滤色透射率 →
  相纸曝光与有效反射密度 → 成品反射谱 × 观看光 → CIE XYZ → 默认色度转换。
  该分支不计算 APD、ADX，也不调用负片至 ACES 的输入变换。

标准输出中的固定输入算法与 ACES 2.0 显示是不同职责。这里保留的是已核对的
2019 ADX 输入算法，不是恢复 ACES 1.x 显示。Status M→APD 经验矩阵只保留为
旧模型回放资料；有透射谱时直接积分 APD，不再引入这项回归近似。

## Status M 来源与数值约定

从本地 ISO 5/3:1984 表 4（PDF 第 7 页、印刷第 5 页）独立提取 42 个对数谱乘积值
和 6 个尾部斜率，再与 [ANSI/ISO 5-3:1995 原表](https://law.resource.org/pub/us/cfr/ibr/001/aimm.it2.18.1996.pdf)
第 17 页核对，数值完全一致。感光谱没有被当作密度计响应。

对谱乘积的 log10 值作线性插值，按原表斜率延伸尾部，再转为线性谱乘积，包含
梯形积分步长并逐通道归一化。谱乘积已包含规定入射条件，不额外乘拍摄或观看光。
它与 APD 标准权重分别加载、分别记录来源。

当前密度计算保留 360–730 nm、2 nm 网格；曝光为 400–720 nm、10 nm，采用
D55 平坦 18% 灰的固定曝光锚点。有限范围遗漏的 Status M 红通道谱乘积面积约
0.0303%，其他通道接近浮点舍入量。该面积比例不是任意透射谱的密度误差保证。
1 nm 密度积分收敛检查在中性阶梯上与 2 nm 结果最大相差 0.000390 D。

这是明确记录的有限波段计算近似。现行 [ISO 5-3:2009](https://www.iso.org/standard/52915.html)
有自己的计算程序；本次没有取得其完整配套数值表，不宣称该版本的规范符合性。
标准 PDF 和提取数值保存在忽略的本地目录，仓库只保存提取器、来源及哈希，
分发权限仍待审查。

## 验证结果

所有显示差按最终 0–1 范围裁切，再取逐像素最大 RGB 通道差，乘以 255。
默认拍摄光 D65、胶片曝光 0 EV；光学放大为 3200 K 模拟钨丝光、零 CMY 滤色、
D50 观看、增益 1.8；输出 sRGB/D65，CIE 1931 2°。另检查 24 色块的 −2、0、+2 EV。

| 检查 | 结果 |
| --- | ---: |
| 用另一份标准原表回算原始 Status M CSV | 最大 0.000232 D |
| 回算 Kodak 原始矢量曲线，未仅对比拟合用的重采样表 | RGB 最大分别 0.000044、0.000060、0.000728 D |
| 独立染料量范围内的总密度下界 | 0.152947 D，保持透射率 ≤1 |
| 原片基与最低平台冲突，保留原片基时的最佳中性拟合 | 最大残差约 0.036398 D |
| 固定 Status M 片基对齐的最大谱密度修正 | 0.053559 D，明确为模型标定 |
| 8 个场景，APD 积分及独立 OCIO ADX/ACES 2.0 输出对照 | 最大 0.002930/255 |
| 8 个场景，光学放大 XYZ 与独立色度输出对照 | 最大 0.002494/255 |
| 两条 65³ CUBE 读回、独立 OCIO 执行 | 文件完整性通过；C++ 与 NumPy 差 ≤2.23×10⁻¹⁶ |

另外直接改变 APD 权重，并把旧兼容矩阵设为不可用：重新拟合的片基、染料量、
感光谱及材料元数据完全不变，光学放大的透射谱、相纸曝光、反射率和显示结果也完全不变。
这项检查验证了职责隔离；APD 输出仍会使用自己的标准权重。

### 与旧结果比较

同一输入和显示条件下，新旧 /2、/3 在 8 个场景中的最大显示变化为 APD 4.381/255、
光学放大 5.056/255。花卉场景分别为 4.134/255、1.718/255；变化不是末端调色造成的。

统一到旧参考的 D55、−0.6 EV 和 ACES 2.0 显示后，8 个场景的 APD 结果全部像素
均在 2/255 内，最大差 0.887/255；花卉场景最大 0.804/255。
这是对存档数值的受控回放，不是实拍胶片准确度证明。光学放大仍使用厂商有效反射密度
近似，与旧稿受实测反射率约束的相纸模型不同；花卉场景默认结果平均差仍为 21.436/255，
不能宣称两种相纸模型已等价。
