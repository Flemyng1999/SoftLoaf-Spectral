# 5207 拍摄光与相纸文档条件

2026-10-27，模型 `5207-paper-reference/4`。
5207 默认采用与 Kodak H-1-5207t 特性曲线一致的 5500 K 拍摄日光近似。
胶片材料直接按 Status M 拟合；APD 只在负片输出分支计算，经 ADX 和输入变换进入 ACES。
相纸使用自己的资料，不能因负片采用 5500 K／Status M 就跟着修改测量定义或光源。

## 5207 默认值

APD 与光学放大配方的默认拍摄光均为 CIE D 系列 5500 K，曝光仍为 0 EV。
原有 D55 平坦 18% 灰曝光锚点保持不变。RAW 的 AP1/D60 工作空间、sRGB/Display P3
显示白点及 A 原始场景参考保持原先定义；拍摄日光不是这些接口的白点设置。
若要对齐旧参考图，仍须另行对齐其 −0.6 EV，不能仅凭 5500 K 假定结果相同。

/1–/3 配方中没有显式色温、只有 `D65` 的旧默认记录，加载时一次改为 5500 K；
已记录的 CIE 色温值保留，曝光、材料 CSV、打印滤色和观看设置也保留。
来源完全匹配后模型版本与配方版本各自更新，原文件不覆盖。旧的 `D65` 简写无法判断
是否曾被手选，按用户这次指定的默认迁移；用户仍可在 /4 中选择并保存 6500 K。

## Ultra Endura：E-4020，2003 年 7 月

本地原厂 PDF 的第 2–4、7 页给出以下条件：

| 项目 | 原文规定或建议 | 应用如何处理 |
| --- | --- | --- |
| 特性曲线测量 | Status A | 按相纸的 Status A 密度近似拟合，不改为 Status M 或 APD |
| 曲线测试曝光 | 0.5 秒；横轴为 log10(lux-seconds) | 保留源条件；当前 EV 控件是相对模型曝光，不冒充绝对照度或曝光秒数 |
| 显影 | RA-4，35°C，45 秒 | 视为这套固定曲线的过程条件；没有温度／时间偏离的化学模型 |
| 光学放大 | 钨丝灯、卤钨灯或放大机灯；按设备厂商要求设定、平衡 | 当前 3200 K Planck 光谱明确是模拟灯；文档未指定其精确色温或 SPD |
| 白光试印滤片起点 | 40M＋50Y | 保留为 CP／二向色滤片单位的参考；不能直接等同当前理想 CMY 密度参数 |
| 评片 | 5000 K ±1000 K，CRI 85–100，至少 538 lux；ANSI PH2.30-1989 | 默认 D50 光谱近似这项观看条件；相对增益不表示已满足 538 lux 或实测 CRI |

这些是原厂参考曲线的条件，不是用户 CSV 的实测条件，也不表示当前模型已经具备
真实放大机、CP 滤片、绝对纸面曝光或荧光散射的完整标定。
纸张公开曲线与标准测量的覆盖限制仍按已有模型记录，不能以补点声称新增测量精度。

当前软件的固定灰平衡使用“18% D65 参考负片＋模拟 3200 K 灯”，与相纸曲线拟合、
纸面 D50 Y=0.1 的锚点共同固定于 LUT 构建前。这是已有的软件标定，没有由 E-4020
规定；本次只将它显式记录，不因修改负片默认拍摄光而悄悄重新归一化相纸。
真实设备应提供灯、滤片、已知曝光及成品反射谱，再替代这些近似。

## 验证

Status M 中性拟合和原始 Kodak 矢量曲线回代不变，最大回代差约 0.00073 D。
新默认 D55 下，8 个高光谱场景的独立输出计算最大差为 APD 0.002582/255、
光学放大 0.002494/255。两条 65³ CUBE 均通过读回和独立 OCIO 执行检查。
38,081 个检查点中，插值误差在 2/255 内的比例为 99.483%、96.767%；
光学放大仍未达到 99% 参考线。RGB 近似与真实彩色胶片的准确度限制没有因此消失。

226 项 Python 回归测试通过；其中 HTTP 用例单独在允许绑定回环端口的环境验证。
新默认、旧默认一次迁移、显式色温保留、相纸文档条件及固定软件灰标定分别有测试。
数值输出留在 `artifacts/5207-d55-default/`，原厂资料及提取数据仍限本地。
