# 本地桌面版 0.1

这一版把配方工作台接入 C++ 计算库，并提供 macOS 窗口。它依赖当前源码目录、
Python 环境和本地材料，适合在本机试用，尚不能作为独立安装包分发。

## 已有功能

- E100、5207 APD 和 5207→Ultra Endura 三种固定流程；通过 CSV 导入感光谱、特性曲线、染料谱及观看光，检查各节点的输入与结果。
- A 固定显示原始场景光谱积分 XYZ 后的 sRGB，经过 OCIO 色度转换，不经过
  胶片或 OpenDRT。B 显示当前胶片配方。内置测量试片的 B 直接计算原始反射谱，普通照片用 RGB 近似。没有实测光谱的普通 RGB 试片，A 明确
  标为输入 RGB 颜色参考，不声称来自光谱积分。
- 打开 8 位 RGB PNG / JPEG。内嵌 ICC 使用相对比色转换到 sRGB；无 ICC 时明确
  按 sRGB 解释。支持单张不超过 16 MiB、1200 万像素，按 EXIF 方向读入。
- 缩小预览，按同一连续光谱配方导出原尺寸、带 sRGB ICC 的 8 位 PNG；照片包
  包含配方、输入解释、试片曝光与计算条件，并验证像素和 ICC 读回。
- 用户选择 2–129 的 LUT 边长，默认 65。导出窗口只提供包含当前显示处理的
  `.cube`，显示一行插值误差，可直接保存。质量参考线不阻止下载；文件读回与
  独立执行仍在后台检查，开发记录不显示在导出窗口。
- 本机自动暂存已应用配方；重新启动恢复。旧配方对照数据保留，不能替换固定 A。
  光谱草稿需要先「应用修改」。
  退出前等待暂存完成，有未应用草稿或保存失败时提示。JSON 导出供独立保存与交换。

5207 APD 与相纸流程已计算，支持负片和相纸 CSV 曲线、放大光色温、曝光及
CMY 理想滤色控制。数值结果与材料边界见[流程核查](5207-pipeline-audit.zh-CN.md)。
RAW 已通过 RawTherapee 5.12 接入原图 sRGB 和线性 AP1 两条独立路径，并加入多图导入、胶片条与后台批量导出。具体设置、缓存和验证范围见 [RAW 双路径与批量试片](raw-handoff-and-batch.zh-CN.md)。普通 RGB
试片入口仍不能验证 RAW 的场景线性、曝光或相机颜色表征。它也不会将已渲染照片
还原为原场景。当前保留平滑光谱先验，两个实验采样库尚未替换工作台默认值。
用户流程已移除「光谱估计」节点。它不是用户需要配置的胶片材料；现有先验
算法暂留后端并记录在计算条件中，不能据此宣称已经完成无重建的直接映射。
E100 和相纸的 XYZ 积分与固定白点处理收在观看节点的「颜色计算详情」，
不再单列不可调的输出接口；负片的 APD/ADX 标准输出节点保留。

桌面工具栏和底部状态按实际视口布局。长内容在中间工作区、右侧设置与侧栏
分别滚动，不再用整页滚动把工具栏推出窗口。原生内容约束在窗口标题栏以下。
流程节点为常驻列表，不提供折叠操作。曲线下方不再重复显示当前配方图例。
光谱模式以材料曲线为主：默认查看标准日光、感光、特性、染料、片基与观看
光谱。源数据用单张大图展示，计算结果收在次级页；不再常驻输入／输出双图。
三通道曲线同时显示，图例仅标颜色，不提供通道切换。E100 与 5207 内置感光图使用
已锁定来源的原厂 PDF 矢量细节，保留原曲线起伏；曝光计算网格仍为 10 nm，
不以绘图点数宣称计算精度。CSV 模板仍导出计算材料的数据；替换曲线后按用户
实际采样点绘图。E100 的矢量细节独立提取自已核对的 E-4000（2018）第 4 页，
R/G/B 分别保留 381/265/385 个绘图点，不能把这些点数视为实测分辨率。
底部只保留一行提示、保存和计算状态，工具栏切换居中。

「计算结果」的取样文字可展开 6×4 色卡抽屉，选择 Colour BabelColor Average
的 24 个色块。启动时默认选 22 号中性灰（neutral 5，.70 D），不默认使用图像中心点。
计算使用对应的实测反射谱和当前配方；选中的色块随节点切换保留，配方改变后重新计算。此取样与试片输入分开，不替换已打开的照片，也不进入配方或
LUT。选择「使用试片取样」可回到图像选点。颜色只用于辨认色块，计算不从按钮的
显示 RGB 反推光谱。

试片模式为独立的图像调整布局：左侧配方列表、中间单图 viewer、右侧调整栏，
支持原图、结果与双图对比；导入照片按钮仅在此模式显示。色块使用 Colour 的
BabelColor Average 24 色卡；自定义曲线的唯一导入格式见 [CSV 规范](spectral-csv.zh-CN.md)。
试片默认采用双图对比，「对比」按钮排在首位。显示外观与 SDR 输出目标共用
光谱模式的配方，可选 OpenDRT Colorful、ACES 2.0 SDR、Display P3 等；具体编码和
上游 LUT 的色域限制见[色彩管理](color-management.zh-CN.md#当前应用的选项)。
旧 ACES 显示配方读取时统一迁移到 ACES 2.0，并增加配方版本；菜单与运行时不再
保留 ACES 1.0/1.1 显示路径。迁移对工作区里的当前配方和对照配方均有效。

反转片与光学放大默认「色度转换」，APD 默认「ACES 2.0」。色度转换直接执行
XYZ D65→目标 RGB 矩阵与传递函数，不经过 OpenDRT LUT。旧文件没有显示默认
版本标记时，其中的 OpenDRT Default 一次性迁移为对应流程的新默认并增加配方
版本；无法区分旧文件的 Default 是自动填充还是主动选择。其他外观保持选中。
归一化后记录 `display.defaults_version=1`，随后主动选择 OpenDRT Default 不会
再次被替换。原始导入文件与已冻结导出不改写，曝光、观看增益、材料及目标色域保留。
外部对照、未通过的材料比较和 LUT 误差见[三管线验证](pipeline-default-verification.zh-CN.md)。

「新建配方…」先选择反转片透射观看、负片 APD 输出或负片光学放大，再建立独立配方，
进入其光谱节点。新配方从对应的内置模板开始，填入 E100 或 5207 的光谱曲线；
光学放大还包含 Ultra Endura 相纸。它不复制当前配方的自定义曲线、曝光或显示设置。
用户可在各节点导入 CSV 替换内置材料。取消选择不创建配方；已有配方与草稿保留。
新建窗口用流程类别作为主标题，默认材料仅在小字注明；新配方名称不加片种前缀。
侧栏上方选择当前配方，主行显示名称，下方注明成像流程；菜单按三种流程分组，
选择项目只打开对应配方，不改变其他配方的流程。名称修改后同步到选择菜单和列表。
下方「已打开的配方」保留，供回看与切换。具体片种在胶片或相纸材料节点显示。

左侧配方与流程节点使用独立的悬停、按下、选中和键盘焦点状态。悬停不覆盖
选中底色；按下不缩放、不移动列表。计算刷新只更新已有行的内容与状态，
保留焦点。重复点击当前配方或节点不重置页面；方向键及 Home／End 切换行，
Tab 进入当前选中项。减少动态效果的系统设置会关闭背景过渡。

右击左侧配方可选择「删除」。右击不切换当前配方；删除当前项后打开相邻项，
删除非当前项不重算当前预览。底部「撤销删除」按次序恢复配方、原位置和已应用
的设置；删除记录随工作区保存，重新启动后仍可恢复。原有 JSON 文件及冻结
导出不删除。存在未应用光谱草稿时，需先应用或还原再删除当前项。
最后一份配方也可删除，此时显示新建／打开入口；重新载入不会补回默认配方。

显示节点默认展示「转换过程」，列出实际 OCIO 矩阵、LUT、传递函数与取样点的
逐步数值。「计算结果」页保留最终 RGB。内部 XYZ 与完整 CTF 的生成和核验接口
仍供开发使用，不再列为普通导出选项。完整来源与误差记录保存在本机生成目录，
不要求用户阅读检查 JSON 或选择内部文件格式。

负片「标准输出」默认展示 APD → XYZ：扣除当前模型片基密度、编码 ADX16 浮点码值、
还原 CDD、CDD→CID 矩阵、趾部查表／直线段、线性曝光、ACES2065-1 AP0 / D60、
XYZ D60 与 Bradford D60→D65。各步列出所选色块的输入和输出，趾部 11 点表可展开。
数值与现有 float64 计算核对，不改变处理结果，不再将 XYZ 配色函数作为这一节点
的默认页面。此处保留锁定的 ACES v1.2 ADX 输入变换；显示节点的 ACES 2.0 配置独立。

## 构建

本机需要 CMake、支持 C++23 的编译器、macOS SDK，以及已有的 Python 3.12 环境。
桌面目标设置为 macOS 14.5 及以后，实际只在本机系统验证。
从仓库根目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-experiment.txt
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DPython3_EXECUTABLE="$PWD/.venv/bin/python"
cmake --build build
ctest --test-dir build --output-on-failure
.venv/bin/python -m spectral_app --check
open "build/SoftLoaf Spectral.app"
```

已经有 `.venv` 时直接从 CMake 开始。原生窗口使用系统 AppKit / WebKit，
没有增加 Qt、Electron 或 Node 运行时。启动检查列出缺少的文件和依赖；它只检查
存在性与可装载性，正式载入时仍需完成中性拟合及来源检查。

本地资料仍按 [资料目录](../data/registry.json) 与 [数据规则](data-and-licensing.md)
准备，不随源码或应用公开打包。默认目录：

- `local/film-color-slides/hyperspectral-demo/output/reversal-E100/data/`：三份 E100 CSV。
- 同一归档 `output/reversal-E100/intermediate/model.npz`：现有 Status A 数值权重。
- `local/film-color-slides/data/`：CIE XYZ、D50、D65 CSV。
- `local/materials/5207-v1/`：独立提取的 5207、相纸、APD CSV 及来源记录。
- `local/materials/e100-plot-v1/sensitivity.json`：可选的 E100 原厂感光绘图细节，
  与 `data/e100-plot-reference-manifest.json` 核对身份，不进入计算材料或配方。
  使用 `python -m experiments.extract_e100_plot <已核对的 E-4000.pdf> <输出路径>` 重提取；
  只需要提取时的可选依赖，应用运行不读取 PDF。缺少这份可选资料时显示原 CSV 点。
- `local/reference-assets/OpenDRT_v1.0.0_mini-config_v2.zip`：锁定的 OCIO 资料包。
- `artifacts/branding/softloaf-cat.png`：用户授权的本地猫标；没有时不影响计算。
- `artifacts/branding/SoftLoafSpectral.icns`：可选桌面图标，存在时随开发包复制。
  2026-10-27 用户比较后选回彩色背景猫标，当前选择记于 `active-logo.json`，
  编辑来源记于 `color-background-edit.json`。原图保存在同目录
  `softloaf-cat-original.png`，黑底莫西干备选保存在 `softloaf-cat-rainbow-mohawk.png`。

开发版资源只记录构建时的源码和 Python 位置，并复制本项目计算库；不能移动到
另一台机器便直接使用。换了目录或 Python 环境，应重新配置构建。

## 计算与核验

`core/` 中的库使用 float64，C ABI 版本为 1。输入与输出均为连续行优先数组，
接口见 `core/include/softloaf/core.h`。Python 绑定检查类型、形状与有限性，
装载失败会报错，不静默改用另一种计算路径。

C++ 负责光谱重建、曝光积分、有效 CMY 插值、光学密度到透射率、观看积分、
XYZ 适应、ACEScct 解码和四面体插值。材料中性拟合保留 SciPy 实现；固定颜色
转换和 OpenDRT 仍由 OCIO 执行。前端与数据服务保留 Python / HTML / JS。
因此这是 C++ 数值内核的混合应用，而不是所有组件都已迁移到 C++。

默认输入为线性 AP1 / D60，场景照明 D65；感光波段 400–720 nm，观看波段
400–700 nm，观察者 CIE 1931 2°。LUT 输入为 ACEScct AP1 / D60，域
[-0.25, 0.75]³，材料输出为带观看尺度的相对 XYZ D65。曝光锚点、固定 D50
适应参考、观看增益、光谱来源及内核二进制 SHA-256 记录于导出条件。
GUI 仍将估计光谱标为估计值。

```sh
.venv/bin/python -m pytest -q
node --test tests/*.test.cjs
```

先构建内核再运行测试。C++ 中间量对照 NumPy float64，绝对与相对容差均为
2e-12；LUT 导出另比较 Python 四面体和 OCIO。导出文件读回、数值实现误差、
RGB 光谱近似误差与真实胶片精度是不同的检查。

## 本机文件与服务

运行文件保存在 `artifacts/application/`：`inputs/` 保存打开照片的本地副本，
`workspace.json` 保存已应用配方，`exports/` 保存生成结果，`desktop.log` 保存
启动诊断。这些文件均在 Git 忽略范围。无法复现的旧工作区保留，不自动覆盖。
不同窗口对工作区的保存采用版本检查，过期窗口不能覆盖新版本。

原生窗口启动一个只监听 `127.0.0.1` 随机端口的服务，只开放明确列出的资源，
检查 Host / Origin。退出会终止它启动的服务；父进程意外退出时服务自行结束。
HTTP 服务可单独运行用于开发检查：

```sh
.venv/bin/python -m spectral_app --port 8773
```

单独服务可通过 `--archive`、`--opendrt`、`--output`、`--core` 指定资料与库位置。
本版没有安装到系统应用目录，没有签名发布、上传资料或公开数据。

试片模式可独立折叠配方栏和底部胶片条：配方名称左侧的侧栏图标控制左栏，胶片条标题处控制缩略图。收起后保留展开入口，预览使用腾出的空间；状态随本机工作区保存。折叠不修改当前配方、照片或曝光，光谱模式的流程节点仍常驻显示。

## 新增实验材料

新建配方窗口可选择新增负片。ECN-2 与 C-41 材料分组显示；负片材料与 APD／光学放大正相方式独立组合。C-41 的 APD 正相标为实验组合。
借用数据、光源和固定放大起始参数见[配方与文件头说明](film-presets.zh-CN.md)。


光学放大现提供独立的 KG3／二向色光谱光路、可选镜头、预闪光和相纸白底 CSV。
新建采用新版，旧配方保留原结果，可在“放大照明”明确切换并撤销。使用入口、
固定起始设置、验证数值和数据边界见[光路更新](printing-optics.zh-CN.md)。
