# 翻拍亮度与 Cineon 参考检查

2026-10-29，Issue #12，`codex/scan-negative-calibration`。本次核对没有更改
应用的曝光、材料、色卡标定、片基选择或缓存。新增的实验与回归测试用于
追踪亮度，不能当作真实胶片绝对色彩准确度验证。

## 反射率光谱测试

在每个曝光波长上填入相同的反射率，使用 CIE D55（5500 K）。18% 平坦灰谱
按已有曝光参考归一化为三个感光通道的相对曝光 1；没有追加显示曝光补偿。
原厂 Status M 曲线拟合材料，获得透射谱，再计算 APD、扣除模型 Dmin、按
固定 RGB 编码增益生成连续 ADX10。密度积分是 APD 响应，不用 XYZ 配色函数。

| 输入 | Cineon 正常负片经验码值 | 本模型 ADX10 R / G / B |
| --- | ---: | --- |
| 零曝光／模型 Dmin | 95 | 95 / 95 / 95 |
| 2% 平坦黑谱 | 180 | 236 / 235 / 224 |
| 18% 平坦灰谱 | 470 | 476 / 484 / 465 |
| 90% 平坦白谱 | 685 | 652 / 669 / 639 |

Digital LAD 常用 445，须与传统正常负片的 18% 灰 470 分开记录。0.002 D/码、
典型胶片 gamma 0.6 对应约 90.3 码/EV。现有 5207 模型在中灰上方一挡得到
R/G/B 约 75.9 / 79.5 / 74.6 码，对应净编码密度 gamma 约 0.50–0.53。
这是该固定材料模型的结果，不是证明所有真实 5207 都有这些值。

Cineon 经验值可发现异常，但不是每种胶片、显影与密度响应都必须精确通过的
拟合约束。当前模型中灰接近传统参考，黑白密度范围较窄；没有为了穿过三个
经验点而修改原厂曲线。传统 CPD 的光谱响应与 APD 不同，ADX 还包含规定的
(1, 0.92, 0.95) 编码增益。因此 ADX10 与 Cineon 有兼容的密度编码尺度，不能
不声明输入度量就把两者当成完全相同的光谱度量和 log-to-linear 变换。

连续码值满足 ADX16 = 16 × ADX10，不使用 65535/1023 直接伸缩码值。使用
官方 OCIO 的 `ADX10_to_ACES2065-1` 再执行官方 ACES 2.0 SDR 100 nits / sRGB，
与本实现的 ADX16 路线相比，阶梯、曝光坡度和 24 色卡最大差约 0.00127 个
8 位码值。独立官方 ADX 输入将中性 ADX10 445 映射为 ACES 0.18，470 映射为
约 0.22191。不能把这些锚点混在一起，但它们的差异也不是两挡。

另使用 colour 的 BabelColor Average 实测 24 色反射谱，插值到当前曝光网格。
其近中性灰块在 D55 / CIE 1931 2° 下相对 Y≈0.1912，输出 ADX10 约
479 / 491 / 471；实测白块 Y≈0.9126，输出约 654 / 670 / 632。XYZ 观察者只用于
描述色卡的场景相对 Y，不替代胶片感光或 APD 响应。曝光坡度超过 100% 的
部分明确是曝光等效辐亮度因子，不称为被动反射率。

命令：`python -m experiments.audit_cineon_reflectance --output <外置卷目录>`。
本机结果保存在外置数据卷 `qa/scan-brightness-2026-10-29/reflectance-cineon/`。
JSON 记录连续与量化码值、原厂材料身份、光源、网格、显示版本和独立比较。

## 真实翻拍为什么暗

当前卷结果采用 0 EV；此前用于观察的 +2 EV 版本在显示前乘以 4。上次将新卷
默认值改成 0 EV，确实会改变与该版本的视觉比较。只检查模型灰点不足以认定
实拍卷曝光已经准确，也不足以认定其本来就欠曝；这项默认修改的依据不充分。

此次实际读取五帧已保留的 half 数据。前向反演到 APD／ADX 的 float64 输出与
官方 OCIO ADX16 最大差约 2.3e-6；XYZ 白点桥接后显示与官方直接 AP0 显示的
最大差小于 0.0014 个码值。65³ LUT 与直接反演在这些场景样本的 P95 差小于
0.18 码，最大约 0.58 码，不能解释明显变暗。未发现本次综合取样导致两挡损失。

第一帧已记录的画面区域内，线性 ACES Y 中位数约 0.0904；第 14、30 帧分别
约 0.0269、0.0187。进入显示变换之前信号已经较低。模型 18% 灰产生 Y≈0.2425，
甚至高于 0.18，因而没有证据支持在全管线中隐藏增加四倍增益。图像中位数
不是场景灰卡，不能据此反推真实拍摄曝光。

输入端另外检查了：

- 在相机数据、联合响应和片基中一致改变三通道乘法尺度，ACES 输出最大差
  约 9.8e-15；没有固定四像元缩放导致的两挡损失。
- 第一帧八个候选联合响应的 Y 中位数约 0.0875–0.1176；关闭平场并重新拟合
  色卡约 0.0819。候选变化不能单独解释四倍亮度差，但仍是模型不确定性。
- 当前片基框没有覆盖画面，也没有通道饱和；靠近齿孔和画面边缘。左侧另两处
  清晰片边的 Y 中位数约 0.0960、0.0981，变化较小。向下移至画面边缘会得到
  不可靠的片基结果，未据此更改当前选区。
- 原平场 G 通道约 45.34% 饱和，旧标定仍依赖外推。没有新测得的有效平场、
  同卷未曝光片基光谱和原场景灰卡，仍不能将模型结果等同于绝对真实曝光。

RAW 的 40 份读取记录及其内容保持不变。处理没有用额外 RAW 解码换取结果。
新增检查连同现有 ADX/扫描参考回归共 13 项通过。
