# 优化采样模型与 GPU LUT 生成

2026-10-28，Issue #11。

核查发现，之前建立并优化的两套采样数据库和模型仍在，但工作台没有接入，
仍使用最小一阶差分近似。原 LUT 烘焙虽然已用 Metal，部分验证仍是整批 CPU
计算，CUBE 读取也会把所有文本行存为 Python 列表。此次接通原有优化成果，
并把应用的 LUT 生成独立为分块模块；没有重新混合两种片类或引入新的训练集。

按用户要求直接升级现有配方，不另建用户备份。配方加入模型身份与来源哈希，
材料、曝光、照明、观看、显示和 RAW 输入开发保持各自的定义。

## 使用的数据与模型

| 片类 | 原采样库 | 选定模型 | 拟合记录 |
| --- | --- | --- | ---: |
| 反转片 | reversal.sqlite，19,213 条谱 | local_512_128，512 条覆盖谱、128 邻居、正则 0.01 | 512 |
| 负片，包括 APD 与光学放大 | negative.sqlite，19,212 条谱 | 来源平衡三阶根多项式，正则 1e-5 | 10,484 |

同一负片换 APD 或光学放大，只改变后续输出，不改变输入近似或 Status M 材料
拟合。反转片不读取负片模型。24 色卡是显示、诊断与来源之一，不是 LUT 唯一
的建立数据。

这些模型是从原库选出的 RGB → 光谱近似。最终 LUT 网格仍由用户选择，
不是把数据库样本逐条当作立方体节点：先确定连续光谱处理，再计算所选网格。
模型使用固定 D65 颜色积分、线性 AP1/D60 输入，33 个波段，400–720 nm。
相机 RAW 仍先由已核验的技术开发进入 AP1/D60；CUBE 输入为 ACEScct。

反转片模型原来按 E100 开发误差选择；负片模型按输入光谱 RMSE 选择，
原负片库没有 APD 或相纸输出标签。不能将它们称作针对全部片种的最优模型。
当前导出使用当前配方重新计算材料、APD 或相纸结果，不使用过期输出标签。

模型、数据库和选择报告由 `data/sampling-priors-manifest.json` 固定身份。
启动检查片类、来源哈希和输入积分矩阵；导出前后再次核对来源。缺失或不匹配
会报错，不静默退回旧模型。原 float64 模型和显式旧近似模式保留作参考。
原始资料和派生模型、LUT 的分发权利仍需逐来源核对。

## GPU 与内存边界

主流程为：ACEScct 解码 → 对应片类光谱重建 → 感光和显影 → APD/ACES、
透射观看或光学放大/相纸 → 显示转换。以上逐点计算、LUT 四面体插值与
生产误差参考由 Metal 执行，与图像预览、照片导出使用同一算法。

局部模型在 GPU 中查找原 512 条谱的邻域，求解原正则化系统；没有额外烘焙
一个近似重建 LUT。负片使用原拟合系数和有符号根特征。保留非负投影与
原来的非黑亮度门限。非常远离训练颜色的数值点不因此获得实测谱的含义。

- 网格按最多 8192 点生成，不建立完整坐标 meshgrid。
- 局部模型的 Metal 派发最多 4096 点，限制每线程邻域暂存的总规模。
- 节点以 float32 文件映射保存，CUBE 逐块写入、逐块解析并准确核对节点。
- 验证用的 C++ float64 插值直接读取 red-fast float32 节点，运算仍为 float64，
  不先复制一张 float64 表。GPU LUT 参数每次导出只准备一次。
- 129³ 节点表约 24.6 MiB，固定参数缓冲上限 32 MiB；大缓冲后续可按需缩小。
- 校验通过后原子发布；中间节点文件不进入最终文件包。所有数据与临时文件在 T7。

CPU 负责已冻结的参数准备、坐标组织、文件/元数据、统计和独立校验，不将这些
称作 GPU 工作。macOS 默认 Metal；明确选择 `--compute cpu` 仍可运行 float64
参考模式，Metal 失败不会自动切到 CPU。历史独立 E100Model 实验入口仍保留，
不代表实际应用的 SpectralModel 默认路径。

## 验证与适用范围

每次导出分别记录：

1. LUT 插值误差：GPU 连续模型对 GPU LUT。
2. RGB 光谱近似误差：原始反射谱的材料结果对 RGB 近似结果。
3. 总误差：原始反射谱材料结果对 LUT。
4. 文件完整性：节点读回、输入域、C++ / NumPy / OCIO 独立执行与 GPU 对照。

验证集包括 8192 个固定种子的 sRGB 点、2049 个中性点、729 个 ACEScct 域内
探针，以及对应片类库中 5376 条留出光谱的 −2/0/+2 EV 条件。它们不参与此次
重新拟合；历史上仍属于开发资料，不能称为新盲测或真实胶片测量。
导出另外抽取最多 512 个点用 float64 连续模型核查 GPU。显示浮点误差界限
为 3e-4；逐波长测试也直接比较 GPU 重建与原 float64 模型。

以当前默认 E100 色度显示、5207 APD/ACES 2.0 和 5207/Ultra Endura 光学放大，
同一留出谱和曝光条件下，平均“最大通道绝对码值误差”为：

| 路线 | 旧输入近似 | 优化输入近似 |
| --- | ---: | ---: |
| E100 透射观看 | 8.908 | 6.685 |
| 5207 APD | 5.536 | 4.937 |
| 5207 光学放大 | 6.086 | 5.330 |

单位为 8 位显示码值。这里衡量相对于当前光谱模型的近似误差，不是相对于
实拍胶片的准确度；也不代表其他片种或照明下必然改善。

全部 26 份材料/流程组合，在三档胶片曝光和 RGB/直接光谱输入下共 156 项
通过 GPU 与 float64 核查。最大显示绝对差约 6.82e-5，最大缩放 XYZ 差约
2.42e-4；APD 密度和相纸独立 CMF/色度积分也单独检查。

Apple M2 Pro 上，129³ 反转片完整导出约 15.59 s，进程峰值约 384.9 MiB；
该进程启动模型阶段已到约 304.8 MiB。节点读回、GPU/float64 和独立 OCIO
检查通过。此结果包含模型、显示资源和验证开销，不是“整个 App 只占分块预算”
的保证，其他硬件和材料设置仍可能不同。

最终负片 129³ 导出约 13.33 s，峰值约 380.1 MiB（模型阶段约 303.3 MiB）。
两次最终测试的 GPU/float64 和 GPU/OCIO 检查均通过。全套回归为 Python
364 项、JavaScript 68 项、CTest 2 项通过；另在实际界面完成新配方的生成、
误差展示和保存入口检查，下载头部包含模型身份、SoftLoaf Spectral 和 Yangming Feng。
