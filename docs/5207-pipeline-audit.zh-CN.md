## 实际顺序

2026-10-27 补充了[旧参考图与当前应用的成片对照](5207-reference-comparison.zh-CN.md)。
旧图与默认配方的曝光位置、拍摄照明、显示变换和材料拟合不同；内部数值检查
不能代替这些条件一致时的端到端比较。

APD：场景反射谱 × 拍摄光 → 三层有效曝光 → 显影后 CMY 与片基密度 →
负片透射谱 → APD 加权积分 → 固定 Dmin、通道增益和连续 ADX16 编码 →
ACES 1.2 ADX16 输入变换 → ACES2065-1 AP0 / D60 → XYZ D65 → OCIO / OpenDRT。
没有翻拍光、相机或逐照片自动校准。内部不先量化成 10/16 位整数。

光学放大：相同的负片透射谱 × 模拟放大光 × 理想滤色透射率 → 相纸三层
曝光 → Ultra Endura 特性曲线及反射密度模型 → 成品反射谱 × 观看光 → XYZ
→ 显示。APD/ADX/ACES 的负片输出不参与相纸曝光。

原始 A 始终为原场景光谱积分 XYZ→sRGB，不经过胶片或 OpenDRT。
内置高光谱场景和 Colour 24 色卡的 B 现在直接使用实测反射谱。
普通照片没有这些数据，B 使用声明的 RGB 光谱先验。

## 修正的问题

图表接口曾将新节点的通道标签序列化成字符串，导致 APD／显示页保留旧图。
现已统一成数组，并用实际界面逐节点核对数值显示；另有格式回归检查。

原界面允许保存 5207 参数，但没有负片或相纸引擎。现在每个节点展示实际
计算的输入和输出，材料变更会重新拟合并参与预览、照片导出和 LUT 构建。
感光谱、特性曲线、染料谱、片基、放大光、滤色谱与相纸曲线支持 CSV；曲线图保持只读。
APD 权重和 ACES 标准转换固定，不能作为任意效果曲线修改。

高光谱预览原来先降成 RGB，再估计反射谱，损失了本已存在的光谱信息。
这条路径仍适用于普通照片；测量试片改走直接计算，避免把近似图当参考。

相纸最初选用任意 logH 中点，默认中灰偏暗。本次改为在原始 5207、3200 K
模拟放大光下固定通道平衡，并求解纸面 D50 Y=0.1 的曝光锚点；默认观看
增益 1.8 后为 Y=0.18。此标定在生成 LUT 前冻结，不从用户照片自动取灰。

## 数值结果

| 检查 | 结果 |
| --- | --- |
| 5207 中性 APD 拟合最大残差 | 0.000230 D |
| 相纸中性 Status A 近似拟合最大残差 | 0.001919 D |
| C++ 与 NumPy float64 中间结果最大绝对差 | 3.56×10⁻¹⁵ |
| ACES v1.2 ADX16 独立实现与 OCIO，1024 点 | 最大相对差 4.22×10⁻⁶；高曝光 AP0 值下最大绝对差 0.00737 |
| 文件验证 | 三条默认 65³ CTF 包均通过 CUBE 读回、独立 OCIO 执行及显示链一致性检查 |

独立 ADX 对照覆盖码值 0–26000，包括不等通道、暗部与高曝光；差异包含
OCIO 单精度运算。另有解析密度、ADX 比例、偏移、负 footroom、半整数
取整、曝光符号、APD/相纸分支隔离及自定义 CSV 材料的测试。

### 65³ 插值与 RGB 近似是两件事

| 流程 | 65³ 插值：连续误差≤2/255 | RGB 近似对光谱参考：连续误差≤2/255 |
| --- | ---: | ---: |
| E100 | 99.094% | 60.410% |
| 5207 APD | 99.609% | 49.575% |
| 5207 → Ultra Endura | 99.215% | 62.335% |

插值检验含 38,081 个域内普通 RGB 构建样本，比较相同连续 RGB 模型与
65³ 材料 LUT 加相同显示链。该比例是合并结果，不保证每张图或整个立方域
都达标。最大残余误差约为 E100 13.96、APD 8.47、相纸 12.57 个连续码值。

光谱近似检验独立于插值：八张历史开发高光谱图，各取固定 48×32 点，
加 24 色卡，在 −2/0/+2 EV 共 36,936 点；曝光变体没有被当成独立场景。
比较同一配方的直接光谱计算与 RGB 先验计算。这不是新的盲测数据，也不是
实拍胶片对照。当前普通 RGB 近似明显达不到 99%；增加 LUT 规模不能解决。

导出窗口另对当前配方固定抽取 scene43 的 48×32 点和 24 色卡，分开显示
RGB 近似与本次 LUT 对直接光谱参考的总误差，不把插值达标称为总误差达标。

完整数值、逐场景记录和构建文件保存在本地 `artifacts/pipeline-audit/`，不随
资料许可未完成的文件公开分发。

## 材料与边界

- 5207 使用 Kodak H-1-5207t，July 2015，第 4–5 页矢量曲线；相纸使用
  Kodak E-4020，July 2003，第 7 页。提取脚本保留坐标、原始曲线点、来源
  哈希和重采样规则。微小曲线逆序用保序投影处理，原始点仍保留。
- 感光谱由 log10 值转为线性能量响应。曲线外的感光尾端假定为零；这不是
  实测零值。5207 灰曝光原点为原厂 Camera Stops 0，在 D55 下以平坦 18%
  反射体归一化；不是绝对 ISO、快门或照度标定。
- Status M 中性目标按 TB-2014-005 的 5207 专用矩阵及偏置转成 APD，之后
  用 APD 权重拟合染料含量。直接由透射谱积分的 APD 不再做该矩阵转换。
  原资料给出的绿色最大矩阵残差为 0.053 D，远大于本模型的内部拟合残差。
- APD 使用 360–730 nm、2 nm 的原始权重和梯形归一化。厂商染料图始于
  400 nm，360–400 nm 使用端点延伸；该区权重占 R 0.0256%、G 0.0115%、
  B 0.2057%。权重小不等于暗部密度误差一定小，不能据此声称完整标准符合。
- 模型片基以厂商最低密度谱为形状，并对齐最低曝光平台的 APD；最大光谱
  密度修正约 0.0626 D。它是冻结的模型 Dmin，不是本项目测得的零曝光片样。
- 相纸使用反射密度近似 R=10^−D；有限带宽 Status A 权重、理想滤片与模拟
  放大光均有明确模型限制。尚未验证散射、荧光、层间效应及已知曝光到
  真实成品反射谱的关系；现有成品反射测量不能补成缺失的曝光标签。
- RAW/RawTherapee/DCP 仍未接入。已渲染 PNG/JPEG 不能视为经过表征的场景
  线性 RAW，也不能恢复拍摄时的真实高光和光谱。

因此，目前可确认的是流程已执行、单位与方向一致、数值实现相符、默认
65³ 插值通过本次抽样参考线。完整胶片观感和普通 RAW 的色彩准确度尚不能
据此确认。
