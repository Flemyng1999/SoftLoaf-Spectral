# 项目说明

2026-10-26

SoftLoaf Spectral 根据光谱曲线和成像参数计算胶片模拟 LUT，计划提供独立
计算库和桌面应用。用户在界面中组合材料与光源、调整参数、比较结果，再
导出 LUT。仓库已有独立重建的 E100 局部参考与本地工作台，尚无可安装的
桌面应用；5207 APD 和光学放大已接入本地参考计算，数值与材料边界见[流程核查](5207-pipeline-audit.zh-CN.md)。

## 范围

核心流程是选择光谱数据和成像配方，调整节点，计算并检验指定输入输出的
LUT。三种模拟分别是三套 LUT 生成配方，共用光谱计算、采样、检验和导出。

普通用户可以打开 RAW、选择胶片、调节效果并导出图像；专业用户可以编辑
光源与材料曲线、检验并导出 LUT。RAW 显影与相机表征交给 RawTherapee，
应用集中处理其后的胶片效果。不打开 RAW 也能生成 LUT，不扩展图库管理。
现有高光谱场景用于建立参考、拟合近似和测试，后续再优化采样，不要求
用户自己提供。两条链与共享参数见[总体设计](system-design.zh-CN.md)。
按颜色覆盖与光谱差异组织的[本地采样库](spectral-sampling-database.zh-CN.md)
已分别为反转片和负片输入建立，包含实测来源、覆盖子集、合成同色异谱和
数值测试点。完成了独立候选的拟合和迭代，尚未发布数据集或切换工作台默认
先验；负片标准成像验证仍待 APD 引擎接入。

相机输入以匹配机型的 DCP 或矩阵配置进行颜色表征。有可靠的光谱响应时，
另行验证它对相机模型的改进；缺少响应曲线不阻止普通 RAW 使用。DCP 不是
相机光谱测量，详见 [RAW 输入与相机配置](raw-input-and-dcp.zh-CN.md)。

第一批材料为 Kodak 5207 负片、Ultra Endura 相纸和 E100 反转片。
完成这些材料的计算和验证后，再增加片种。

| 流程 | 计算内容 |
| --- | --- |
| 5207 APD | 胶片曝光、负片透射谱、标准 APD 密度和锁定版本的标准输出；不模拟翻拍因素 |
| 5207 光学放大 | 负片透射光、放大机照明与滤色、相纸曝光、成品反射谱和观看 |
| E100 透射观看 | 胶片曝光、显影后染料、观察光与透射颜色 |

预设须说明使用的光源、材料和处理步骤。同一种胶片的 APD 输出、放大和观看
结果并不相同。Ultra Endura 是相纸，不能用它代替电影拷贝片的模型。

APD 是 Academy Printing Density，依 SMPTE ST 2065-2:2012 定义；ADX 是
SMPTE ST 2065-3:2012 定义的密度交换编码。负片的标准谱权重、完整覆盖和
归一化须按原标准冻结，不能改动后仍称标准 APD。标准输出参考限定为
[aces-core v1.2（2019）](https://github.com/aces-aswf/aces-core/tree/v1.2)，
其 Dmin、通道尺度、编码和具体转换版本仍待补齐并验证，不用普通 RGB 反相
代替。该路径目前只保存草案；详见[方法](science-and-pipelines.md#negative-apd-and-standard-output)。

官方负片资料的 Status M 密度通过绑定片种的 3×3 矩阵与偏置接入 APD。
这一步隐藏但默认执行，不增加界面节点或启用开关。专业详情保留来源、
原始密度、矩阵和残差；已直接从透射谱计算的 APD 不重复转换。用户提供
的技术说明已核对，含 5207 示例，但尚未导入数值或完成标准实现，见
[APD 与 ADX](apd-adx.zh-CN.md)。

## 实现

光谱参考程序使用已知场景光谱计算胶片响应，保存曝光、密度和透射／反射谱
等中间结果。普通照片缺少这些光谱数据，另用 RGB 近似模型处理。
RGB 结果与光谱参考比较，用未参与拟合的完整场景检查误差。

胶片 LUT 根据当前光谱节点采样生成。用户替换胶片、光源、滤色、相纸或
观看条件后，应用更新所选样本的光谱与图像预览，再生成对应的 LUT。
RGB 加速模型也以这套光谱配方的结果为参照，不另做一套无关的调色效果。

LUT 只保存参数固定、逐像素执行的颜色转换。依赖整张图像或多张照片
估计参数的操作，要在导出前完成。

参考程序计划用 Python 编写，使用 float64。普通图像先在场景线性
ACEScg 中实验。应用内部将胶片 LUT 与 OpenDRT 分开，胶片 LUT 拟接受
指定范围的 ACEScct 输入，输出带有固定尺度和观看含义的相对 XYZ D65。
完整效果导出包含显示处理时，使用端不再叠加显示转换。本地 OCIO/CTF
包保留材料 LUT 与显示操作；单个包含显示处理的 CUBE 另行验证，不能
把内部 LUT 的通过结果沿用到该文件。
工作空间、曝光范围和插值方式都随文件记录。
LUT 规模由用户选择，65³ 是默认建议。界面展示样本范围、近似与插值误差、
量化结果和体积；99% / 2 码作为参考线，不因未达到而禁止导出。

固定颜色转换使用 OpenColorIO，显示成像采用 OpenDRT 的 OCIO 配置。
光谱程序输出的 XYZ 保留观看条件，再按明确的白点和亮度尺度接入显示
模块。预览、图像导出和显示烘焙 LUT 共用保存的处理配方。配置版本、
显示目标和实际文件编码都须记录，见 [色彩管理与显示输出](color-management.zh-CN.md)。

以后再考虑其他 Log 输入、CLF／OCIO 配置导出和 GPU 滤镜。OCIO 执行库从
第一份预览与图像导出开始使用。

包含显示处理的 LUT 与工作空间中的风格 LUT 分别定义。相纸观看时算出的
XYZ 对应指定的观察条件，不能直接当作场景线性颜色使用。

## 桌面界面

主界面以光谱配方、节点参数、光谱图、图像预览和 LUT 导出为主。
预览照片的相机配置、白平衡和曝光放在图像输入区域。
三种模拟采用固定的成像流程，各节点允许替换材料、光源并调整参数；标准
APD 权重与标准转换属于版本化定义，不作为自由改动后仍保持标准名的参数。
常用设置直接显示，原始曲线、拟合和定标等内容展开后查看。选择图像中的
像素或区域，可以比较各阶段的光谱、曝光、密度和颜色数值。

光源、胶片、滤色和相纸等节点在流程条中直接可选。用户可以在自己的 RAW
上换一个元件、比较变化，再保存为配方；后台处理 LUT 生成和缓存更新，
界面显示当前结果的配方版本和预览质量。

节点清单和图表要求见 [光谱节点与桌面界面](spectral-nodes.zh-CN.md)。

## 与前期实验的关系

前期实验在同一组八张高光谱照片上计算了上述三种成像过程。仓库保存
实验摘要和文件校验值，计算将在这里独立复现。旧实验所用的私有应用
代码、配置和测量文件，须分别确认授权后才能迁入。

E100 的中性密度回代误差小于 0.001 D。相纸模型在 71 个留出色块上，
平均 ΔE76 约 4，第 95 百分位约 15。这两项都不能代替完整成像流程的
实测验证，详情见 [实验记录](../research/README.md)。

相关开源项目见 [参考资料](prior-art.md)。后续测试分别报告材料模型、
RGB 近似、程序实现和 LUT 导出的误差。与其他方法比较时，使用相同的
输入和观看条件。

## 使用与发布

先实现 E100 参考程序、RGB 近似和 LUT 导出，再独立实现 5207 APD 与
光学放大。桌面应用在计算和导出经过验证后开发，第一阶段集中在计算程序。

每份预设记录材料版本、冲洗模型、光源、曝光基准、密度定义、输入输出
空间、显示处理及数据来源。整卷定标和自动曝光可以在图像处理中计算，
导出 LUT 时必须固定。颗粒与光晕另行开发。

原创代码和文档采用 AGPL-3.0-only。资料许可单独记录，允许公开阅读的
PDF 不直接视作可重新分发的数据。
