# 项目说明

2026-10-26

SoftLoaf Spectral 从前期胶片光谱实验开始，准备做成独立的胶片模拟库和
LUT 生成工具。主要面向摄影、视频调色及色彩研究。

## 范围

第一批材料选用 Kodak 5207、Ultra Endura 相纸和 E100 反转片。先完成少数
材料的计算和验证，再增加片种。

| 流程 | 计算内容 |
| --- | --- |
| 5207 数字化 | 胶片曝光、负片染料、翻拍照明、相机响应和固定的数字化处理 |
| 5207 光学放大 | 负片透射光、放大机照明与滤色、相纸曝光、成品反射谱和观看 |
| E100 透射观看 | 胶片曝光、显影后染料、观察光与透射颜色 |

同一种胶片在不同流程下会产生不同结果，所以预设要说明整条流程。
相纸和电影拷贝片分别建模，Ultra Endura 只用于相纸流程。

## 实现

只做 RGB 调色，无法直接检验材料和光源的作用；全用光谱计算，普通照片又
缺少所需的数据。因此项目分为光谱参考计算、RGB 近似和 LUT 导出三部分。

参考计算使用已知场景光谱，保留中间的曝光、密度和透射／反射谱。
RGB 近似与参考结果比较，并用未参与拟合的场景检查误差。LUT 导出只接受
参数已固定、逐像素执行的颜色转换。

参考程序计划用 Python 和 float64。普通图像的实验工作空间先用
scene-linear ACEScg。第一份兼容 LUT 计划接受明确范围的 ACEScct 输入，
输出已经包含显示处理的 sRGB；使用时不能再叠加一次显示转换。
工作空间、曝光范围和插值方式都随文件记录。以后再考虑其他 Log 输入、
CLF/OCIO 和 GPU 滤镜。

显示烘焙 LUT 和仅改变风格的工作空间 LUT 分别处理。相纸观看时算出的
XYZ 有观察条件，不能直接当作场景线性颜色使用。

## 与前期实验的关系

前期已在同一组八张高光谱照片上跑通三条流程。新仓库保存其摘要和文件
校验值，后续独立复现计算。旧实验使用的私有应用代码、配置及测量文件，
需要分别确认授权后才能迁入。

E100 的中性密度回代误差小于 0.001 D。相纸模型在 71 个留出色块上，
平均 ΔE76 约 4，第 95 百分位约 15。这两项都不能代替完整成像流程的
实测验证，详情见 [实验记录](../research/README.md)。

已有开源项目也在做光谱胶片模拟，见 [参考资料](prior-art.md)。本项目会
分别报告材料模型、RGB 近似和 LUT 导出的误差，方便判断问题出在哪一步。
是否优于其他方法，要用相同条件的实验比较。

## 使用与发布

第一阶段建立仓库和文档；随后依次实现 E100 参考程序、RGB 近似及 LUT，
再迁入 5207 数字化与光学放大。暂不开发完整桌面界面，也不先扩展大量片种。

每份预设记录材料版本、冲洗模型、光源、曝光基准、密度定义、输入输出
空间、显示处理及数据来源。整卷定标和自动曝光可以由滤镜计算，导出 LUT
时则必须固定。颗粒与光晕作为独立图像处理步骤开发。

原创代码和文档采用 AGPL-3.0-only。资料许可单独记录，允许公开阅读的
PDF 不直接视作可重新分发的数据。
