# 节点工作台

这个应用首先用来组织光谱节点、计算和导出 LUT。照片用于检查结果。
应用分为光谱与试片两个工作区，沿用同一套配方和计算。

## 主窗口

- 左侧先选固定成像流程，下面按实际顺序列出节点。APD 输出与相纸之间
  切换时，共用负片设置保留；另打开一份配方仍是独立对象。
- 中间默认展示选中材料的曲线：标准日光、感光光谱、特性曲线、染料光谱、
  片基或观看光谱。每次以一张完整曲线图为主，注明量、单位与横轴。
  计算结果收在最后一个次级页，三通道数值不伪装成光谱。
- 右侧只放当前节点的参数。切到观看节点不会继续显示胶片曝光或显示外观。
- 胶片节点默认打开“感光光谱”，可切换“特性曲线／染料光谱／片基光谱”；
  观看节点默认打开观看光谱。各节点的“计算结果”排在材料页之后。相关数据归在所属节点中，不再开一套材料工作台。
- 试片模式左侧为配方列表，中间为单图 viewer，右侧为调整栏。默认显示结果，
  可切换原图或双图对比；没有流程节点列表或“试片设置”。照片入口仅在该模式显示。
- 内置预览提供高光谱场景与 Colour BabelColor Average 24 色卡，4×6 排列。
  A 固定为原始场景 XYZ→sRGB，B 为胶片结果；普通 RGB 输入的 A 明确标为 RGB 参考。
- 流程节点常驻，不提供折叠。工具栏居中切换工作区；未保存与计算状态放在底部单行栏。

固定流程选择器代替三张常驻配方卡片。已打开的配方放在侧栏下部按需展开；
保存、撤销、导出仍在工具栏。沿用系统明暗外观及用户授权的猫标，记录见
[品牌来源](../design/gui-v1/branding.md)。

## 光谱怎样调整

选择节点后默认进入对应的材料曲线页。源曲线只读，作为此工作区的主要内容；计算结果在次级页查看，不提供拖动、逐点
输入或倍率调整。自定义曲线统一通过 CSV 替换；文件格式、单位与完整波段
见 [CSV 输入规范](spectral-csv.zh-CN.md)。页面提供当前曲线模板，保留原始网格
和导入文件 SHA-256。名称与来源可以填写，曲线数值在外部文件中准备。

拍摄日光另提供 4000–10000 K 滑块和数值输入，用 CIE D 系列生成模拟光谱。
6500 K 保持原 D65；改变拍摄光时保持有限波段光度与材料灰锚点约定。

编辑先保留为当前配方的光谱草稿，右侧明确标记“待应用”。“应用修改”
通过校验后才替换配方并更新结果。切节点不会丢草稿，保存或生成遇到未
应用的编辑会返回相应数据页。读取文件或拟合期间锁住源数据控件，避免
异步导入覆盖正在提交的修改。撤销配方后，源曲线也回到同一版本。

修改材料会成为“自定义材料 · 基于 E100”。它使用同一参考模型，但不是
原厂 E100 的实测效果。染料和特性曲线需完成不超过 0.001 D 的中性拟合，
并能解出固定 D50、Y=0.1 的相对灰锚点；失败保留原配方。这只验证模型
内部相容性，不证明真实胶片色彩准确。观看光按白 Y 归一化，亮度另用
观看增益调整。

## 流程与能力

| 流程 | 固定顺序 | 当前状态 |
| --- | --- | --- |
| E100 透射观看 | 拍摄照明 → 胶片曝光与显影 → 透射观看 → 显示输出 | 实际 float64 参考与 OCIO/OpenDRT；支持上述四类自定义数据 |
| 5207 APD 输出 | 共用负片阶段 → 标准 APD 密度 → 标准负片至 ACES 转换与输出接口 → 显示 | 实际计算、CSV 材料与可选规模 LUT；材料准确度待测 |
| 5207 光学放大 | 共用负片阶段 → 放大照明／滤色 → 相纸曝光与显影 → 成品观看 → 输出与显示 | 实际计算、CSV 材料与可选规模 LUT；材料准确度待测 |

彩负输出不设置翻拍光源、翻拍相机或翻拍定标。APD 响应是固定标准。
Status M → APD 则属于材料内部默认处理，不增加主流程节点或启用开关。
替换负片材料时自动匹配对应矩阵与偏置，专业详情提供原始密度、转换结果、
来源、有效域与残差。缺少匹配数据时提示并阻止该材料的 APD 输出，不能
让用户在未知矩阵间试选。透射谱直接积分出的 APD 不重复转换。
这些处理已接通；数值复现与边界详见
[APD 与 ADX](apd-adx.zh-CN.md)。

APD 密度、ADX 编码和负片至 ACES 转换分别记录，不能画成一套任意可调的
设备参数。已接通固定版本，并记录数值、来源及近似条件。

RGB 光谱近似的输入参考仍为固定 D65；模拟拍摄光可由日光色温替换。
RAW/DCP 开发与任意相机响应尚未实现。macOS 开发版已接入 C++ 内核。缺少实现的节点说明具体缺项，
不显示假光谱或占位 LUT。节点输入要求见[输入契约](lut-generation-inputs.zh-CN.md)。

## 配方和导出

配方包含材料、胶片曝光、流程、观看和显示条件、完整自定义数据、来源
与版本。试片输入曝光只改变检查输入，不进入胶片 LUT。A 使用原始输入参考；
历史配方快照仍可恢复，但不能替换 A。实验入口保留旧的完整配方对照。

保存下载可重开的命名 JSON；打开时校验数据和引用。同一 ID 的文件再次
打开不会重复建库。导出等待已提交的修改，冻结参数指纹，不仅比较版本号。
旧任务不能把后来修改过的配方标作已完成；恢复可用配方使用确切的成功
快照，并保留未完成修改的撤销历史。

内部材料 LUT 为 ACEScct AP1/D60 → 相对观看 XYZ D65，四面体插值，
各通道范围 −0.25～0.75。边长可选 2–129 的整数，常用 17、33、65、129，
默认 65；规模属于导出设置，不改写材料配方。它需要后续显示链。默认完整效果包使用原生 CTF，
包含材料 LUT 和固定 OCIO/OpenDRT 操作，输出标准 sRGB，仅用于兼容宿主。
当前显示链的逆一维 LUT 无法由该 CLF 写出器表达，所以没有强行再次烘焙。

每次生成都读回文件并用独立 OCIO 检查。连续码值和 8 位取整后，逐像素
各通道误差不超过 2/255 的比例分别展示，以 99% 为参考线，未达到仍可
下载。还显示样本数、平均、P95、最大码值误差和文件体积，用户自行权衡。
这是相对同一连续 RGB 模型的插值误差，不是光谱近似或真实胶片精度保证。
文件读回不一致仍阻止下载。更改材料或规模后重新检查，不沿用旧结果。

## 运行

[界面](../design/gui-v2/index.html)、[光谱编辑控件](../design/gui-v2/spectral-editor.js)、
[本机服务](../experiments/gui_recipe_server.py)、[接口约定](gui-workbench-contract.md)。
已有实验依赖和本地资料时，从仓库根目录运行：

```sh
.venv/bin/python -m spectral_app --port 8773
```

访问 `http://127.0.0.1:8772/`。材料、试片、猫标及生成结果仍在忽略目录，
没有作为公开资产发布。[第一版](../design/gui-v1/prototype.html)保留供比较，
其计算仍是示意；[走查记录](gui-task-walkthrough.zh-CN.md)区分代理意见、
实际任务检查和后续用户对操作结构的修正。

光谱图统一仅显示 400–700 nm；相纸感光谱例外，横轴显示 400–750 nm，
不为原始数据以外的区域补造采样。特性曲线使用 log10 曝光横轴。
这些是显示范围，计算与 CSV 导出保留原始数据和波段。观看节点和负片标准
输出节点提供只读的 CIE 1931 2° XYZ 配色函数页，不将三个 XYZ 数值还原成
虚构光谱。
