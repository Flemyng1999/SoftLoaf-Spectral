# 色卡标定与负片正相

桌面应用的“负片正相”工作区处理翻拍负片。它独立于生成胶片风格的“光谱”和
“试片”工作区，不会将已拍摄的负片再次当成场景去模拟曝光。

## 使用

1. 点击顶部第一枚色卡图标，导入透射色卡 RAW、该卡实测透射光谱 CSV；
   平场可独立导入并选择，也可不使用。将示意图旋转、镜像至与照片一致，
   依次定位 CC01 和 CC24，核对图上的 24 个标记；透视明显时拖动四角调整，再计算标定。
2. 导入同一次翻拍条件下的负片 RAW，可以多选。选择实际负片材料，在一张图的
   已显影、未曝光片边框选片基；同一卷只需选择一次。
3. 点击“一键正相”。应用生成冻结的 LUT，并处理胶片条中的全部图像。
   默认 65³，新一卷曝光补偿 0 EV，APD → ADX → ACES 2.0 SDR 100 nits → sRGB。
4. “保存 LUT…”下载密度输入的 CUBE；CLF 接受平场校正后的线性原生相机 RGB，
   内含对数。点击“导出正片…”生成原尺寸、内嵌 sRGB ICC 的 PNG，多张打包为 ZIP。

标定保存在外置数据卷，重启可继续使用。改变机身、镜头、ISO、快门或光圈会
被阻止使用原标定；光源、光路改变也必须重新标定，软件无法只凭 EXIF 检测它们。
换片卷需重新选片基。当前材料选择为 Kodak VISION3 的四种 ECN-2 负片，真实
翻拍验证以 5207 为主；不据此声称其他材料已有独立实拍准确度验证。
“新一卷”清空当前胶片条及片基选择，保留原件、标定、已生成结果与 RAW 阶段。
扫描的 5207 默认使用此前实拍对比的参考模型，不由材料目录中的另版曲线覆盖；
材料或计算版本变化后旧预览不再标为已应用，需重新正相。

顶部标题左侧的侧栏图标收起或展开“扫描标定”栏；重启后保留展开状态，
与“试片”的配方栏分别保存。右击标定可删除，在该栏右键菜单中“恢复上次删除”可恢复。
删除仅移出标定列表，保留原件、RAW 阶段和已生成文件；删除当前标定后需另选标定。
状态查询遇到短暂断连时有限重试，不重发上传或 RAW 开发。导入期间合并工作区查询，
胶片条按图像身份更新已有项目，避免每次进度变化都重建全部缩略图。

## 色卡 CSV

UTF-8 文件，首行为 `# softloaf.transmission-target/3`，用
`# target=000003` 记录实体卡号。各光谱列使用固定 ID **CC01–CC24**，读取按 ID
匹配，列顺序不限。完整表头为：

```csv
wavelength_nm,CC01,CC02,CC03,CC04,CC05,CC06,CC07,CC08,CC09,CC10,CC11,CC12,CC13,CC14,CC15,CC16,CC17,CC18,CC19,CC20,CC21,CC22,CC23,CC24
```

未知、缺失、重复或补零不符的 ID 会报错并指出字段，不自动按列号替代。
界面、示意图和 CSV 模板使用同一套 ID。排列保持 colour 的 6×4 ColorChecker
顺序，CC01 在左上，CC24 在右下；colour 的英文色名仅作为内部对应关系。
示意颜色采用 BabelColor Average D50 xyY，经 Bradford 适应至 D65、编码为 sRGB，
只用于定位。标定始终使用导入文件的实测透射率。

照片转正后点选 CC01、CC24 的中心，生成横平竖直的 6×4 网格。两点不能唯一
确定透视，倾斜时开启“透视微调”拖动角点，并检查全部取样点。旋转和镜像只影响
展示，取样反映射到原始 RT 坐标。

旧位置编号、数字编号和已导入的英文键文件仍按原含义读取，供已有标定复现；
新模板统一使用 CC01–CC24。当前实测卡的转换仅改变表头，波长和透射率逐值
相同。继承定位要求完整波长、每条光谱和重排后的投影网格精确对应，不能根据
文件名、卡号或近似颜色猜测。已有标定和正片不自动重算或覆盖。

随后每行一个波长和 24 个透射率。波长单位 nm，严格递增，至少覆盖
400–700 nm；透射率使用 0–1 比例。需 31–8192 个波长行，不接受百分数、
空值或反射色卡数据。对话框可下载仅包含格式说明和表头的模板。
用户的 000003 是透射卡，不能替换成 colour 库中普通 24 色反射卡的参考值。

## 处理与边界

RAW 先按黑白电平归一化为线性原生相机 RGB，使用单位通道增益，无 DCP、
白平衡或显示曲线。新平场采用 64×48 低频网格，以各通道中央 20% 的有效值
归一化，仅修正空间不均匀，不代替白平衡；无测量支持处向单位增益混合。
中心饱和或过暗时拒绝生成新平场。旧标定保留原二次模型和饱和外推提示，
不能把外推当成实测恢复。色卡与参考透射率拟合非负联合采集响应，用嵌套的
六列留出验证选择正则化参数；不是分别测得的相机感光谱和灯具光谱。

逐图空间平场校正发生在 LUT 之前。LUT 内是相机通道密度 → 受约束材料反演
→ 透射谱 → APD → ADX → ACES → sRGB。材料继续按 Kodak Status M 测量拟合，
APD 仅在输出分支使用。片基对齐、材料、标定和观看条件全部冻结进 LUT 身份。
改变曝光补偿或网格需重新点击“一键正相”；不会重复读取 RAW。线性 ACES
节点与显示曝光分开缓存，曝光编辑复用材料反演结果。新的空间平场不强制联合
响应的各通道积分为 1，采集尺度由色卡拟合。更换或关闭平场会重算对应色卡
标定并应用整卷，避免标定与图像处理条件不一致。

文件回读检查所有 LUT 节点，并由 OCIO 独立执行 CLF。另以 1024 个密度域样本
比较 float64 直接模型和 LUT 插值，界面简要显示 P95 与最大 8 位码值误差。
这是插值误差，色卡留出误差也只是这张卡的采集预测误差；两者均不代表真实
负片正相后的独立色彩准确度。模型范围外采用 LUT 端点限制，不能保证恢复。
目前缺少该卷独立 APD 密度和原场景颜色参考。

原件、标定、LUT、预览及导出均保存在配置的外置数据卷。本机缓存维护只清理
可再生的预览；扫描 RAW 的 half/full 两个阶段受到保护。预览最多短边 2048，
小图不放大；完整导出使用区域读取、分块平场和 LUT、流式 PNG 写入与回读，
不建立全尺寸浮点正片。首次预览开发一次、首次完整导出开发一次，随后切换、
修改、清理预览缓存和重启均复用保留阶段。文件变化或阶段中断时停止，不隐式
再解码。LibRaw 自身的完整开发仍需传感器缓冲，不是零内存解码。

这是依赖本地材料、LibRaw helper、ExifTool 和 Python 环境的开发版。
实测色卡和材料资料的再分发许可未完成审核，当前生成结果限授权本地使用。

## 综合几何与平场，2026-10-29

顶部用两个 SVG 图标打开平场、镜头几何工具，悬停显示名称。平场支持导入
1–8 张 RAW、选择与关闭；镜头工具支持公开 Lensfun 配置、手动径向畸变、

显示转换不参与测量。取样坐标不受成片旋转和裁切影响。

Lensfun 只生成坐标参考，不处理像素；选定的径向映射经过坐标残差检查后冻结。
当前使用本机 Lensfun 0.3.4 的公开数据库，未包含其他应用的私有配置或代码。

## 响应舍入与删除标定（2026-10-29）

空间平场标定的受约束最小二乘可能在数值边界留下约 1e-20 的负响应。
旧片基对齐对任何负值均报 `Invalid border alignment`，把这类舍入误差误判为
无效片基。拟合现在投影回声明的非负约束；读取已有标定时，按每通道响应尺度
检查 float64 的 64 epsilon 容差，只把容差内的负舍入量归零。明显负值、非有限数、
