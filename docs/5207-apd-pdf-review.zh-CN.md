# 5207 APD 与 PDF 的逐项核查

2026-10-26，Issue #2。按用户要求，由三个独立 agent 分别审查 PDF 公式与表格、
5207 材料建模、ADX→ACES 与导出；主审随后重跑权重、材料探针、独立标量转换和相关测试。
本次只核查并记录，没有更改运行代码、默认标定或用户材料。

结论：APD 加权积分、5207 Status M→APD 矩阵和 ADX 编码与所给 PDF 对应；
不能据此称整条 5207 模拟严格复现 PDF，或已证明真实胶片色彩准确。
PDF 从已测得的负片透射谱开始计算 APD，当前程序需要先用额外的材料模型生成透射谱。

## 材料模型的假设与验证缺口

### 中性曲线拟合不能证明彩色曝光准确

当前路线是固定 CMY 染料谱与片基，先将厂家中性 Status M 曲线转换为估计 APD，
再求中性曝光轴上的染料量，各层按自己的有效曝光查表。这个显影模型没有由该 PDF 规定。
其最大中性拟合残差 0.000229802 D，只证明模型能贴合这些目标。

PDF 第 30–31 页的转换本身也是经验回归：97 个拟合色块，另列其他片样残差。
5207 的 all 行最大 RGB 残差为 (0.016, 0.053, 0.010) D，不能因内部拟合更小而忽略。
需要独立的真实 5207 彩色曝光→透射谱/APD 片样，验证预测的透射谱和密度；
目前缺少这项证据，也未验证层间效应或染料谱随浓度变化。

### 片基作了有影响的模型校准

`_negative_fit` 用三个 APD 权重形状基函数调整厂家最低密度谱，使其积分密度
对齐最低有限曝光平台。最大谱密度改变为 0.062585 D，发生于 692 nm。

| Dmin 来源 | R | G | B |
| --- | ---: | ---: | ---: |
| 厂家最低密度谱的 APD 积分 | 0.212457 | 0.547412 | 0.838084 |
| 当前模型校准后的 APD | 0.172461 | 0.570282 | 0.833436 |

厂家谱的红 APD 高于最低目标，非负染料无法同时满足二者，所以当前程序选择修改片基。
PDF 第 15 页将 Dmin 定义为零曝光密度；第 18 页明确允许假定或实测 Dmin，
因此不能把模型 Dmin 直接判为编码违规。但最低有限曝光平台未证明等于零曝光，
也没有独立实测验证这种谱形修正。

固定同一透射谱，仅替换编码用 Dmin，连续 ADX16 会移动约
(+319.964, −168.322, +35.327) 码。这是隔离 Dmin 选值的敏感性试验，
不是另一套完整物理模型，也不能直接换算成显示 RGB 的同等码值误差。

### 短波覆盖限制

Kodak 蓝层感光曲线从约 360 nm 起，当前曝光端仅使用 400–720 nm / 10 nm。
在 D55 与已绘感光谱下，400 nm 以下占平谱蓝层曝光约 8.675%。逐通道中灰锚定
会吸收尺度差，不能将这个比例直接称为默认照片的曝光误差。

独立反例是两条反射谱在 400–720 nm 均为 0.18，仅让 360–400 nm 分别为 0 与 1。
完整谱计算、中灰归一后，蓝层 H 为 0.913251 与 1.395191，差约 0.61138 EV；
当前输入无法区分它们。这里证明的是丢失短波变化不可恢复，不是常见照片的统计误差。

另一个独立问题是厂家染料与片基谱从 400 nm 起，程序将端点延伸到 360 nm。
低于 400 nm 的 APD 蓝权重占 0.2057%，但权重小仍不能证明密度误差一定小。
界面只显示 400–700 nm 的要求是绘图裁切，不应成为科学计算删去资料的理由。

### 连续 ADX 与整数交换文件

内部默认不量化，使用连续 `adx16_float` 接入 ACES，以避免 LUT 构建重复量化。
这与公式尺度一致，但不是 PDF 规定的 unsigned integer ADX16 交换文件。
将来真正写 ADX 文件时，还需核验取整、越界统计、位深和文件读回。

## 可复现的实现缺陷

1. **自定义材料没有绑定片种与转换。** `_validate_negative_material` 只校验结构、
   单位及波段，`route_material` 对自定义材料仍调用同一个 `_negative_fit`，
   一律使用内置 5207 矩阵。修改名称和来源为其他片种仍能通过。
   PDF 第 23 页的转换是产品专属；需要材料 stock/revision 与匹配转换身份校验。
   这是保护缺口，不代表用户已经导入过其他片种。
2. **D55 灰曝光锚点有小偏差。** 分母用未经相同亮度归一的 D55，运行阶段
   `scene_light(5500)` 又按 D65 的 Y 归一；18% 平谱得到 H=1.00537513，
   即 +0.00773391 EV，而元数据写 0。应统一定锚和运行的光源归一方式并增加断言。
3. **导出包漏入 Academy 许可。** 导出函数写出 `ACES-LICENSE.md`，但打包与
   下载列表未包含它。独立 9³ APD 导出确认磁盘存在、ZIP 内缺少。
   这不改变像素计算，但应在分发前补齐；资料本身的发布权限仍需分别审查。

## 检验及后续顺序

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider \

```

这些测试不能替代上文指出的片种身份、D55 锚点与真实彩色片样验证。
独立权重解析、完整 CTL 标量对照及材料探针是本次审计用临时程序；
本报告记录其输入、假设和结果，没有将临时探针冒充已有自动回归覆盖。

建议先修正可复现的实现缺陷；再明确区分实测片基与平台拟合片基，补齐短波覆盖
及其不确定性；最后用独立彩色片样验证材料模型。不要通过重新贴合中性曲线
宣称解决了彩色准确性，也不要把更大的 LUT 当成材料模型误差的解决办法。

普通 RGB 输入还有独立的光谱先验误差。当前配方 scene43 的 48×32 点加 Colour 24，
在 −2/0/+2 EV 共 4680 点上，连续 RGB 模型相对直接光谱参考仅约 32.26% 在
2/255 内，P95 约 24.15/255。该结果不包含 LUT 插值误差，也不是实拍胶片验证；
它与先前八场景合并统计使用不同样本，不能混用百分比。
