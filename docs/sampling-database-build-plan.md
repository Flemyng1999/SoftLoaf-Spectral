# 采样数据库建立与迭代

2026-10-26，执行用户已确认的[设计](spectral-sampling-database.zh-CN.md)，沿用
Issue #2 与当前任务分支。反转片、负片分别建库、选样、拟合和记录测试。
不合并两类材料的标签。已有源文件与其他编辑保持不变。

1. 增加 SQLite 数据契约与测试：原始／公共波段、质量标记、来源分组、
   片类检查、采样清单和输出标签。跨片类读取、来源泄漏和错量纲必须报错。
2. 增加光谱近似测试与实现：全局先验作为对照；局部、曝光齐次的正则拟合
   作为候选。先验证颜色回代与曝光缩放，再与 float64 胶片参考比较。
3. 建立两个本地库，分别生成实测覆盖子集、可实现合成目标、同色异谱压力
   组与纯数值探针。负片标准输出未实现时只保存输入，不生成虚假 APD 标签。
4. 按整场景划分拟合／开发／审计，先根据开发结果调整质量分层、权重、
   近似和样本数，再冻结选项做留出审计。旧开发资料不称最终独立盲测。
5. E100 以连续模型、33³／65³ LUT 分别检查近似与插值，保留误差分布、
   范围与文件读回结果。只达到某个参考比例不限制用户尺寸选择或下载。
6. 更新实测结果和复现说明。完整运行测试，逐库重新打开、检查哈希和数据
   划分。源资料和派生资产留在忽略目录，发布权限仍按来源分别记录。

主要文件：`spectral_lut/sampling_db.py`、`spectral_lut/reconstruction.py`、
`experiments/build_sampling_database.py`，以及相应测试和结果记录。
