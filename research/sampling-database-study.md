# 光谱数据库采样首轮实验

2026-10-26。本实验支持[数据库设计](../docs/spectral-sampling-database.zh-CN.md)，
只做几何、选样和同色异谱诊断，不建立正式数据库或更改默认重建方法。

## 三项检查

1. 在固定 RGB 域中取 512 个扰动 Sobol 点，用线性规划检查是否存在对应
   的有界非负谱。保持 D65、CIE 1931 2°、400–720 nm／10 nm、有限波段
   Bradford 到 AP1/D60 的定义。分别检查上限 1 和曝光缩放上限 16；不声称
   这是全色域体积的精确测量。
2. 以场景 1、5、6、16 每四行／列取点，得到 20,916 条候选谱；场景
   31、38、43、50 每八行／列取点，得到 5,376 条留出谱。按预算 256、512
   比较随机三个种子、ACEScct 最大最小距离、Lab 最大最小距离及 Lab 与
   八维标准化谱形 PCA 的联合距离。保持重建方法相同，不在留出数据调权重。
3. 对 AP1≈(0.18,0.18,0.18) 求三组极端有效曝光差的合成谱。约束谱值 0–1，
   相邻 10 nm 差不超过 0.08，二阶差不超过 0.025。检查回代与约束残差，
   再用现有 E100 光谱参考和固定显示链检查输出差。

颜色距离为 D60 适应后 CIELAB 的欧氏距离（ΔE76），不当作严格视觉均匀。
联合距离对三个颜色轴与八个标准化谱形轴分别作总尺度归一化，是本轮明确
的实验选择，不是已经验证的最优权重或自然材料概率。

先验采用现有未中心化二阶矩、相对岭项 1e-6 和负谱投影；只比较连续模型，
没有 LUT 插值，因此选样结果不能解释为某种 LUT 尺寸的精度。
测试曝光为 -2、0、+2 EV，总计 16,128 个条件样本；显示沿用 OpenDRT
v1.0.0 Default 和已核验的标准 sRGB 编码。

## 结果与解释

几何检查：线性 AP1 [0,1]³ 的 512 个目标中，459 个在单位反射模型下可行；
当前 ACEScct [-0.25,0.75]³ 中只有 71 个可行。曝光上限放宽到 16 时分别为
510 和 193 个。经过变换的编码 sRGB 样本两种条件均为 512 个。没有出现
求解器未知状态；成功样本的最大颜色等式残差小于 3.6e-15。

512 点的 Lab 选样比随机对照有更好的留出颜色覆盖，在这项线性先验测试中
也有较好的输出结果；联合谱形距离没有进一步改善。256 到 512 点的变化
并不单调改善输出。完整数值表列在设计文档，未将本轮最优结果当成默认。

三组构造谱输入回代最大误差小于 1.4e-16；E100 模型显示后最大通道差约
134.01、123.18、133.83 个码值。这是刻意构造的模型压力结果，不是实测
胶片、自然场景误差分布或概率下界。它验证了同一 RGB 并不唯一决定当前
模型的光谱结果，不能用更密的 RGB 点取消这种多值性。

候选池和留出池含有大于 1 的源反射因子，未裁切或改变原始数值。其含义
需要额外核对；这类记录不等于上面 LP 所假设的普通 0–1 漫反射材料。
候选池这类谱为 518/20,916，留出为 74/5,376；512 点联合距离选样中有
120 条，Lab 选样有 63 条。源池占比约 2.48%，联合选样升至 23.44%，因此
需要先按材料模型和测量质量分层；不能据此断言源记录都无效。
最大最小距离可能偏爱离群点，联合 PCA 标准化可能放大噪声，均待进一步
分析。全部八张图均曾用于项目开发，当前四图留出只对本次拟合成立，不能
当作新的最终盲测。

这些数字不能证明数据库会提高真实照片或所有胶片配方的准确性。下一轮
需要匹配预算、明确来源和质量分组，比较更多重建方法并增加未使用的材料
与场景。评价同时保留覆盖、光谱与输出误差，不能只根据单一通过率选方案。

## 复现

```sh
python -m experiments.sampling_database_study \
  --budgets 256 512 --lp-log2 9 \
  --output artifacts/sampling-database-study
```

使用固定实验依赖，以及已有本地 E100 资料、八张 HSI 和官方 OpenDRT 包。
没有安装新依赖或读取其他应用的私有代码。输出 `report.json` 保存版本、
源数据哈希、距离尺度、条件和全部结果；`study.npz` 保存所选索引与压力谱，
`sampling-study.png` 显示几何、覆盖、误差和压力谱。本地输出不随 Git 分发，
原始资料和派生输出的公开权利仍待分别审核。
