# IT8 反射谱与 LUT 构建初检

2026-10-26。目的：先验证资料，再尝试以 IT8 实测反射谱建立 RGB 到光谱的
近似，由胶片物理参考生成 LUT。IT8 在这里是构建素材，不只用于误差检查。

## Colour 是否内置

核对本地固定版本 Colour 0.4.7 的 `SDS_COLOURCHECKERS` 及包内 Python 源文件，
未发现 IT8 条目或 IT8 源文件匹配。内置光谱包括：

| 数据 | 色块数 | 波段与间隔 |
| --- | --- | --- |
| BabelColor Average | 24 | 380–730 nm，10 nm |
| ColorChecker N Ohta | 24 | 380–780 nm，5 nm |
| PMC | 30 | 400–700 nm，10 nm |

`babel_average`、`cc_ohta` 和 `ISO 17321-1` 等是相应数据的别名；本地数值
检查确认 ISO 17321-1 与 Ohta 相同，不能重复计为独立样本。
`CCS_COLOURCHECKERS` 中的 SG 等色度坐标也不等于反射谱。

按项目的历史参考范围，另核对
[Colour 0.3.15 的光谱目录](https://colour.readthedocs.io/en/v0.3.15/generated/colour.COLOURCHECKERS_SDS.html)：
列出 BabelColor Average、ColorChecker N Ohta 及别名，没有 IT8。

IT8 对应靶标类型和测量／交换规范，不代表所有纸材和批次共享一份通用
反射谱。必须标识具体材料、批次和测量文件；不能由参考 Lab 反推“实测”光谱。

## 本次验证的资料

从 [Wolf Faust 的原始资料页](https://www.colorreference.de/testdata/index.html)
取得反射式 Set 14 的光谱与色度参考 ZIP，只使用其中标准 IT8 靶标第 5 张。
它与另外四张大色块集分开记录。元数据声明：

- Kodak Professional Ultra Endura，Testscan14-5，2006-07-10，黑色背衬。
- 288 个色块，每块 41 个实测波长位置，380–780 nm、10 nm。
- 光谱列为 `SPECTRAL_PCT`，读取后除以 100；参考为 D50、2°。
- 所检查的文件未完整确立仪器几何和可追溯测量不确定度，仍需补齐。

源文件保存在本地，不随代码分发。公开下载不代替数据复用和派生 LUT
的发布审查。ZIP 与成员校验值见 [资料目录](../data/registry.json)。

### 数据与色度检查

字段数、样本数、色块 ID、同块的波长网格均相符；288 条光谱全部唯一，
无缺值、非有限数或超出 [0,1] 的反射率，范围为 0.0000005–0.911579。
光谱文件与配套参考文件的同名色块、XYZ 和 Lab 完全对应。

按 CIE 1931 2°、D50，在已测 380–780 nm 内积分，理想反射体 Y=100。
原始测量仍为 10 nm；5 nm 和 1 nm 是 Sprague 插值，不是新增实测数据。
没有补齐两端缺失波段，也未为追近参考值拟合颜色校正。

| 积分网格 | 对配套 Lab 的平均 ΔE00 | P95 | 最大 |
| --- | ---: | ---: | ---: |
| 原始 10 nm | 0.04082 | 0.09488 | 0.12040 |
| 插值 5 nm | 0.01105 | 0.02120 | 0.02986 |
| 插值 1 nm | 0.00994 | 0.01882 | 0.02452 |

独立 float64 求和与 Colour `Integration` 在同网格的 XYZ 最大差小于
3.6e-14（Y=100 尺度）。插值后没有出现负反射率或大于 1 的值。
源 XYZ 只保留两位小数，不能要求其回算暗色 Lab 与直接光谱积分完全相同。

文件说明参考色度由这些光谱计算，因此这证明读取和数值链路自洽，
不证明原始仪器测量、荧光处理或标准符合性，也不验证真实胶片。

## 用它实际生成 LUT

先做一个简单基线：仅从上述 288 条谱学习未中心化二阶矩，加入固定相对
岭项 1e-6，计算能匹配输入 RGB 的线性光谱估计，再将负波段投影到零。
该先验随曝光等比例缩放，不对输出颜色另行拟合胶片风格。

```text
IT8 反射谱 → 在固定 D65 下计算 RGB，建立光谱先验
ACEScct 网格 → 线性 AP1/D60 → IT8 先验估计光谱
→ E100 曝光、显影、透射与 D50 观看 → 相对 XYZ D65 LUT
→ 同一 OCIO / OpenDRT → 标准 sRGB 检验
```

实际生成并读回 33³、65³ CUBE，另生成原最小一阶差分先验的同尺寸对照。
输入域 [-0.25,0.75]，四面体插值；E100 和显示条件沿用
[现有参考](hsi-raw-lut-comparison.md)。输入是理想色度 RGB，未经过相机、
DCP 或 RAW 解码。重建／曝光波段为 400–720 nm，没有外推 IT8 光谱。

未用自然场景、ColorChecker 或胶片结果来调节该先验。筛查集为八张已有
HSI 开发场景，每 16 行／列取一点，每图 336 点；各检查 -2、0、+2 EV，
合计 8,064 个样本。曝光通过缩放入射量表达，不把大于 1 的数值解释为
普通反射率。没有输入点越出 LUT 域。它们未参与本次拟合，但仍是旧开发
场景，不能称为新的最终盲测集。

下表为三通道误差均在 2/255 内的比例，格式为“连续值／实际 8 位量化”。

| 构建先验与网格 | LUT 对连续 RGB 模型的插值误差 | LUT 对直接光谱参考的总误差 |
| --- | ---: | ---: |
| IT8 二阶矩，33³ | 97.56% / 98.95% | 53.60% / 59.02% |
| IT8 二阶矩，65³ | 100.00% / 100.00% | 54.43% / 59.97% |
| 原平滑先验，33³ | 96.44% / 98.24% | 58.38% / 63.27% |
| 原平滑先验，65³ | 99.73% / 99.78% | 60.65% / 65.28% |

IT8 的 65³ 在自身训练色块上，总误差比例为 64.70% / 68.63%，原平滑
先验为 45.49% / 51.16%。IT8 改善了本纸卡上的近似，却没有改善自然场景。
在另外两套 24 色 ColorChecker 上也没有形成稳定优势。独立 CUBE 与 OCIO
四面体读回的 XYZ 最大差为 7.13e-7 以下。

这项结果允许继续把 IT8 作为构建素材，但不支持将该简单线性先验设为
更准确的默认方法。也不能推论所有 IT8 构建方法都不可行。后续可比较带
反射率约束的非线性重建或局部谱基；保持测试集不参与选择和拟合，并补充
其他材料与自然反射谱，检查不同光源、曝光、同色异谱和输入边界。
增加 LUT 尺寸不能消除 RGB 到光谱近似的误差。

反射纸卡不是负片透射样本，不能把它当作 Status M / APD 的独立配对测量。
Set 14 的谱也用于过往相纸研究；重用时不声称独立验证该相纸模型。

## 复现与输出选择

```sh
python -m experiments.validate_it8_data \
  --spectral-zip data/raw/testscan14cgt.zip \
  --reference-zip data/raw/testscan14.zip \
  --output artifacts/it8-validation/report.json
python -m experiments.it8_lut_trial \
  --spectral-zip data/raw/testscan14cgt.zip \
  --reference-zip data/raw/testscan14.zip \
  --grids 33 65 --scene-stride 16
```

另需现有本地 E100 资料、高光谱场景和 OpenDRT 参考包。数据与生成 LUT
仍在忽略目录，未发布。完整数值、版本、源文件和 LUT 哈希写入 JSON。

LUT 规模由用户选择，65³ 为默认建议。99% / 2 码是误差参考线，不是导出
禁令。分别展示近似误差、插值误差、样本范围、量化结果和文件体积，由
用户选择。文件损坏、读回不一致或缺失计算资料仍属于实现／数据错误。
