# 采样库建立、测试与调整

2026-10-26。按[采样设计](../docs/spectral-sampling-database.zh-CN.md)建立本地
0.1 试验库。反转片与负片分别保存数据库、选样清单、模型和验证目标。
尚未公开发布，也不代表真实胶片已通过实测验证。

默认目录为 `artifacts/sampling-database/`，受 Git 忽略规则保护。

原始物体光谱可以来自同一批可追溯资料，成品库不交叉读取标签、选样或
模型。记录具有片类命名空间，打开库和加载模型都检查片类。负片元数据
不沿用 E100 的观看增益、密度拟合或输出定义。

负片目前完成的是输入采样与重建库，尚不能称为针对 5207 APD 输出优化
后的最优数据。APD/ADX-to-ACES 链未实现，不生成负片 LUT 或最终图像
误差；库也禁止为该未实现状态写入假 APD 标签。光学放大需另加相纸标签。

## 来源、质量与划分

来源为八张 Manchester HSI、两套 Colour 内置 24 色反射谱和已验证的
Wolf Faust IT8 Set14-5。两套 ColorChecker 同属一个拟合来源组，不当作
独立测试。原始波长与数值以 little-endian float64 保存，保留来源、哈希、
许可状态和场景／色块 ID。

| 划分 | HSI 场景及规则 | 样本数 |
| --- | --- | ---: |
| 拟合 | 1、5，每四行／列取点；另加 336 个色卡谱 | 10,794 |
| 开发 | 6、16，每八行／列取点 | 2,688 |
| 留出审计 | 31、38、43、50，每八行／列取点 | 5,376 |

拟合中 310 条谱超出当前 0–1 有界反射率假设，原值保留但不进入此模型
的拟合集；合格拟合谱为 10,484 条。开发和审计保留原值，并另报审计有界
子集。来源组和派生压力组不跨划分，不把相邻像素随机分到训练和测试。

共同计算波段为 400–720 nm、10 nm。色卡更宽的原始网格仍在库中，计算
时取覆盖交集；请求缺失波段会报错，不外推或补零。这不是完整 APD 波段
或窄带照明的验证。

两库使用独立种子产生单位曝光、线性 AP1 [0,1]³ 颜色目标。合成谱满足
RGB 等式、0–1 谱值和二阶差分上限 0.025，并最小化总变差。每库的 512
个目标都保存求解状态，没有用裁切后的另一种颜色代替不可行目标。
另存 1,024 个 ACEScct 域内点、257 个灰轴点和 8 个角点作为数值探针。

两套同色异谱组各用三档中性输入、三个目标方向生成。反转片目标为 E100
有效曝光差；负片目标为通用谱形投影，未借用 E100 作为负片输出。
这类合成记录是压力样本，不表示自然界出现频率。

## 测试后的调整

保留原最小一阶差分先验为对照，比较全局二阶矩、局部正则先验、二／三阶
根多项式光谱残差和来源平衡权重，每片类共 17 项配置。没有预先认定更多
样本或更复杂的方法更好。

局部先验按亮度归一化后的颜色寻找邻域，以边界归零的连续权重拟合谱形，
用原先验作正则锚点。根多项式拟合颜色积分零空间内的光谱残差。两者在
非负投影前保留输入颜色，并对正曝光缩放保持齐次；投影后的颜色回代另报。
没有强制估计谱的单位曝光上限，不能将它们当作实测材料。根特征的曝光
性质参考 [Finlayson 等，2015](https://ueaeprints.uea.ac.uk/id/eprint/52673/)；
这里的光谱残差拟合是独立实现，不声称复现该文实验。

反转片以开发集的平均最大通道绝对码值误差为主目标，P95 为次目标。
选定 `local_512_128`：512 条覆盖选样、128 邻居、相对正则 0.01。
1,024 条选样没有在此目标上胜出。

负片输入端独立以开发谱形 RMSE 选择，选中来源平衡的三阶根多项式，
正则 1e-5，使用全部 10,484 条合格谱。没有用 E100 或 APD 显示分数选择。
两个选择均不使用留出审计分数决定；八张图都是历史开发资料，不能称为
新的最终盲测。

## 反转片结果

E100 float64 参考使用 D65 曝光、D50 观看、增益 1.8、CIE 1931 2° 和有限
波段 Bradford 桥接。显示为 OpenDRT v1.0.0 Default 与已核验的标准 sRGB。
输入为理想色度 AP1，没有相机、DCP 或 RAW 解码误差。5,376 条留出谱各
检查 -2、0、+2 EV，合计 16,128 个条件样本。

以下误差取每个样本三个通道中最大的绝对差，单位为 8 位码值。

| 连续 RGB 模型对直接光谱参考 | 原先验 | 调整后 |
| --- | ---: | ---: |
| 平均最大通道误差 | 6.0093 | 4.4993 |
| P95 | 29.6690 | 20.5777 |
| 最大 | 87.1243 | 82.4611 |
| 三通道均在 2/255 内，连续值 | 55.12% | 61.63% |
| 同指标，实际 8 位量化 | 60.14% | 66.11% |

再对原、新模型分别生成相同尺寸的 CUBE。输出均为相对观看 XYZ D65，
后接相同显示链：

| 内部 LUT | 插值误差在 2/255 内，连续／量化 | 对直接光谱参考的总误差在 2/255 内，连续／量化 | 总误差均值 |
| --- | ---: | ---: | ---: |
| 原先验 33³ | 95.21% / 97.50% | 52.41% / 57.20% | 6.1033 |
| 原先验 65³ | 99.50% / 99.68% | 54.83% / 59.58% | 6.0082 |
| 调整后 33³ | 87.99% / 92.80% | 56.27% / 61.39% | 4.9997 |
| 调整后 65³ | 99.30% / 99.49% | 60.63% / 65.64% | 4.6000 |

新模型减少总误差，但对 33³ 网格的插值要求更高。65³ 的插值达到 99%
参考线，不表示 RGB 近似或真实胶片达到 99%。保留全部误差和剩余样本；
尺寸仍由用户选择，构建程序的 `--grids` 支持 2–129 的整数边长。

## 负片输入结果

这里仅比较单位曝光的 5,376 条留出输入谱，没有负片感光、APD 或显示。
RMSE 用反射因子的无量纲数值计算，不能与上表码值误差直接比较。

| 光谱回代 | 原先验 | 独立选择的负片输入先验 |
| --- | ---: | ---: |
| 平均光谱 RMSE | 0.04362 | 0.03929 |
| RMSE 的 P95 | 0.11777 | 0.09415 |
| 最大 RMSE | 0.24502 | 0.20616 |
| RGB 回代最大绝对差 | 0.01918 | 0.00472 |

不能据此推断 5207 或相纸成像改善，也不能选择负片最终 LUT 的最优采样。
接入独立 5207 标准 APD 参考后，需重新做材料相关选择和测试。

## 文件与复现

- `reversal.sqlite`、`negative.sqlite`：独立数据库。
- `models/reversal.npz`、`models/negative.npz`：检查片类的独立模型。
- `reversal_33.cube`、`reversal_65.cube`：新模型的内部 XYZ 试验 LUT。
- `reversal_baseline_*.cube`：原先验对照。
- `report.json`：数据／代码／模型哈希、条件、版本和全部比较。

SQLite 读回检查谱长度、有限数、波长、质量标记、来源和跨划分泄漏；NPZ
检查片类和数值；CUBE 由 OCIO 与 float64 四面体求值器比较。错片类、损坏
数据、未实现负片输出和缺失波段均报错。已有数据库不会被覆盖。

```sh
python -m experiments.build_sampling_database \
  --it8-spectral-zip data/raw/testscan14cgt.zip \
  --it8-reference-zip data/raw/testscan14.zip \
  --grids 33 65 --output artifacts/sampling-database
```

另需固定实验依赖、已有 E100 数值资料、八张 HSI 和官方 OpenDRT 包。重复
构建须选新的输出目录。源资料和派生资产留在本地，公开权利按来源审核。
普通工作台默认先验尚未切换，本轮交付为数据层、独立候选和可复现验证。
